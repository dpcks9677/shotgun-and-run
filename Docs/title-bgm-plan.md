> **상태:** 시안 승인 → 에셋 교체 적용  
> **범위:** 타이틀 씬 BGM 한 곡의 제작과 교체  
> **관련 문서:** [shelter-bgm-plan.md](shelter-bgm-plan.md) (처음 만든 어쿠스틱 곡, 쉘터로 이동) / [dungeon-bgm-plan.md](dungeon-bgm-plan.md) / 제작 도구 `Docs/tools/audiogen/title.py`

## 1. 목표

- 임시로 넣어 둔 외부 곡(`GameTitleBGM.mp3`, 5분 10초, 출처 · 라이선스 불명)을 **게임 분위기에 맞게 새로 설계한 곡**으로 교체한다.
- 타이틀의 첫인상은 **묵직하고 스산한 금관**으로 잡는다. 습격 호른 SFX와 같은 계열의 악기라 세계관이 통일된다.
- 처음 만든 어쿠스틱 포크 곡은 포근한 분위기라 타이틀에 맞지 않아 **쉘터 BGM으로 옮겼다**([shelter-bgm-plan.md](shelter-bgm-plan.md)).

**제외:** 던전 · 쉘터 BGM 변경, 재생 코드 변경(`SceneBgmPlayer` 그대로), 레이어 방식 재생.

## 2. 곡 설계

| 항목 | 값 |
|---|---|
| 음계 | D 프리지안 (D E♭ F G A B♭ C) |
| 템포 · 길이 | 54 BPM, 4/4, 16마디, 3,136,000샘플(44.1kHz, 71.11초) 단순 무한 루프 |
| 악기 | 튜바(드론) · 트롬본 3성(코랄) · 프렌치 호른(멜로디). 모두 가산 합성 금관 |
| 음량 | RMS -20 dBFS, 피크 약 -5 dBFS |
| 출력 | 시안 `Docs/drafts/audio/title_loop.wav`(gitignore) → 최종 `Assets/06.Sounds/Title/TitleBGM.ogg` (Vorbis, 약 0.6MB) |

### 2.1 구성

- **코드 순환(4마디씩):** Dm → B♭ → Gm → E♭. 마지막 E♭에서 루프 처음의 Dm으로 이어지는 부분이 프리지안 종지(♭II → i)다.
- **튜바:** 구간마다 근음 하나(D2 · B♭1 · G1 · E♭2). 앞뒤 구간과 한 마디 겹쳐 크로스페이드하고 2마디 주기로 숨 쉬듯 진폭이 변한다.
- **트롬본:** 코드마다 3성. 튜바와 같은 방식으로 겹쳐 바뀐다.
- **호른:** 4마디 프레이즈 4개. 제시(모티프 A–F–G–B♭ → D) → 응답(한 단계 위) → 고조(최고음 B♭4) → 하강(비우며 복귀). 음 시작에 40센트 스쿱, 느린 비브라토를 넣고, 2박 뒤 되돌아오는 먼 메아리를 낮은 음량으로 섞는다.
- **금관 음색:** 가산 합성이며, 소리가 클수록 고배음이 살아나 밝아진다(실제 금관의 성질). 작게 불 때는 어둡고 둔탁하다.
- **공간감:** 길이 3.2초 홀 리버브(루프 꼬리를 앞으로 감는 원형 합성곱)를 38% 섞는다.
- **여운:** 호른 릴리즈 0.4초, 8박 같은 긴 음은 끝으로 갈수록 줄어든다. 첫 시안에서 음 끝 여운(릴리즈 1.2초 · 리버브 5초)이 길다는 피드백이 있어 줄였다.

### 2.2 모티프

쉘터 곡의 핵심 모티프 A–F–G–B를 B♭으로 바꿔(A–F–G–B♭) 이어받았다. 두 곡이 같은 세계의 다른 면(포근한 쉘터 / 위압적인 타이틀)으로 들리도록 하기 위함이다.

## 3. 이음새 처리

- 코드 구간 사이는 raised-cosine 엔벨로프로 겹쳐 붙이고, 루프 경계를 넘는 음과 리버브 · 메아리 꼬리는 루프 시작으로 감아 붙인다(원형 처리).
- `check.py`의 이음새 검사(점프 · 앞뒤 50ms RMS 비율)를 통과한다. OGG 변환 후에도 샘플 수가 3,136,000으로 같다.

## 4. 적용

| 단계 | 내용 |
|---|---|
| 에셋 | `Assets/06.Sounds/Title/TitleBGM.ogg`를 금관 곡으로 교체(새 GUID). 임포트: Compressed In Memory, Vorbis, Preload |
| 씬 | `TitleScene`의 `TitleBGM` 오브젝트(`SceneBgmPlayer`)의 `_bgmClip`을 새 클립으로 교체 |
| 재생 코드 | 변경 없음 — `AudioManager.PlayBgm`의 루프 · 페이드(0.5초) 그대로 |

## 5. 재현

```
cd Docs/tools/audiogen
.venv/Scripts/python.exe title.py   # Docs/drafts/audio/title_loop.wav 생성 + 루프 검증
```

같은 코드는 항상 같은 WAV를 만든다(이름 기반 시드). 최종 OGG는 이 WAV를 Vorbis로 변환한 것이다.

## 6. 남은 일

- 플레이 모드에서 타이틀 진입 시 루프 이음새와 음량(BGM 슬라이더 기준) 청취 확인.
- 합성음이라 실제 금관보다 인공적으로 들릴 수 있다. 필요하면 이후 사운드폰트나 DAW 작업물로 교체한다(구성과 모티프는 유지).
