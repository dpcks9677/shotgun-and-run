## 1. 확정 사항 (2026-10-12)

### 1.1 구성: 총 13개

| 분류 | 수 | 대상 | 수주 방식 |
|---|:-:|---|---|
| 탐사 (강제) | 2 | Z1 (Q1 대장간의 숫돌) · Z2 (Q2 마법사 구출) | 스토리 슬롯, NPC 컷씬이 수주 |
| 탐사 (수주형) | 8 | Z3 · Z4 · Z5 · Z6 · Z7 · Z8 · Z9 · Z10 | 의뢰 슬롯, 게시판 |
| 디펜스 (구역 정화) | 2 | Z4 · Z7 | 의뢰 슬롯, 게시판 |
| 엘리트 처치 | 1 | Z5 엘리트 스나이퍼 | 의뢰 슬롯, 게시판 |

- **탐사 10종 = 메인 존 10곳.** Z2 탐사는 Q2(H2 홀 엘레나 구출)로 대신한다. Q2는 Z2 존 안이 아니라 H2 홀에서 진행되지만 Z2 탐사를 완료한 것으로 친다
- 보물찾기 · 상자형 회수 · 디펜스 2단계 · Z4 · Z7 외 존의 디펜스는 이번 DB에 없음

### 1.2 해금 규칙

| 대상 | 해금 조건 |
|---|---|
| 수주형 탐사 8종 (Z3 ~ Z10) | **Q2 완료 시 전부 해금** (랜덤 스폰 해금과 같은 시점). 고위험 존(Z5 · Z8)도 같음 → 명세 9.3의 "다른 8곳 중 4곳 완료" 잠금은 쓰지 않음 |
| 디펜스 Z4 · Z7 | **그 존의 탐사 완료만.** 명세 9.3의 "완료 후 그 존을 다시 방문하고 탈출" 조건은 쓰지 않음 (`Requires Zone Visit After Unlock` 끔) |
| 엘리트 처치 Z5 | **Z5 탐사(`SQ_EXP_Z5`) 완료** (디펜스와 같은 방식) |

### 1.3 완료 조건

| 분류 | 판정 |
|---|---|
| 탐사 | 대상 존 상자 1개에 확정으로 들어가는 **인증 아이템을 들고 탈출** (`Item Source = ZoneChest`) |
| 디펜스 | 런 플래그 `Z4_DEFENSE_CLEARED` / `Z7_DEFENSE_CLEARED` + 탈출 |
| 엘리트 처치 | 런 플래그 `Z5_ELITE_SNIPER_KILLED` + 탈출. **드랍 아이템 없음** |

- 사망하면 런 플래그 · 아이템은 무효, 수주는 유지 (명세 9.3)

### 1.4 맵 배치

| 대상 | 배치 | 동작 |
|---|---|---|
| 디펜스 Z4 · Z7 | 존 안에 **퀘스트 활성 오브젝트** 1개씩 던전 씬에 배치 | 퀘스트를 수주한 런에만 E 2초 홀드로 상호작용 → **존 출입구 봉쇄** + 디펜스 웨이브(1.5) 시작. 모두 클리어하면 문이 열리고 런 플래그. 진행 중 주기 습격 타이머 정지 (명세 4.3 · 4.6) |
| 엘리트 Z5 | 던전 씬에 몬스터를 배치할 때 Z5 혼합 수비대의 EliteSniper로 함께 배치 | 퀘스트 수주 여부와 관계없이 항상 있음. 처치 시 런 플래그를 올리고, 판정은 수주한 퀘스트만 받음 |

## 3. 진행 흐름 (평가 빌드 3런 기준)

```
Run 1  Q1 (E1 고정) ── Z1 숫돌
Run 2  Q2 (E1 고정) ── H2 엘레나 구출 = Z2 탐사 → 랜덤 스폰 해금
         └ 수주형 탐사 8종 전부 게시판에 열림 (Z3 ~ Z10, 고위험 Z5 · Z8 포함)
Run 3  수주형 탐사 최대 3개 동시 진행
         └ Z4 / Z7 탐사 완료 → 그 존의 디펜스 열림
Run 4~ 디펜스 · 엘리트 처치 · 남은 탐사
```

- 평가자가 3런만 하면 디펜스 · 엘리트 처치는 **수주 가능 상태까지만** 보게 됨 (4런째부터 진행 가능)
