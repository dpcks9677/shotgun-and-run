# 쉘터 BGM 제작 계획서 (미스터리 어쿠스틱 포크)

> **작성 일자:** 2026-10-14  
> **상태:** 승인 완료, 쉘터 씬에 적용 (처음에는 타이틀 곡으로 만들었으나 타이틀은 금관 곡으로 새로 설계해 이 곡을 쉘터로 옮김)  
> **범위:** 쉘터 씬 BGM 한 곡, 이후 BGM에 재활용할 모티프 정의  
> **관련 문서:** [title-bgm-plan.md](title-bgm-plan.md) / [dungeon-bgm-plan.md](dungeon-bgm-plan.md) / 제작 도구 `Docs/tools/audiogen/shelter.py`

---

## 1. 목표

- 쉘터에서 재생할 **포근하면서 낯선 분위기의 곡**을 새로 설계한다. 쉘터는 던전과 달리 쉬어 가는 공간이다.
- 신비한 느낌의 악기와 반복 루프로 이루어진 **미스터리 어쿠스틱 포크**. 다크 판타지 앰비언트가 아니라 서정적이고 포근하면서 낯선 느낌을 낸다.
- 던전 BGM(D 프리지안, 75 BPM)과 타이틀 BGM(금관, D 프리지안, 54 BPM)과는 독립된 곡이다.

**제외:** 던전 BGM 변경, 재생 코드 변경(`SceneBgmPlayer` 그대로), 레이어 방식 재생.

---

## 2. 곡 설계

| 항목 | 값 |
|---|---|
| 음계 | D 도리안 (D E F G A B C) |
| 템포 · 길이 | 72 BPM, 4/4, 16마디, 2,352,000샘플(44.1kHz, 53.33초) 단순 무한 루프 |
| 악기 | 하프(뜯는 현) · 플루트(멜로디) · 뮤직박스(모티프 반짝임) · 현 드론(D2 · A2 · D3) |
| 음량 | RMS -20 dBFS, 피크 -6.5 dBFS (던전 앰비언트 -26 dBFS보다 약간 크게) |
| 출력 | 시안 `Docs/drafts/audio/shelter_loop.wav`(gitignore) → 최종 `Assets/06.Sounds/Shelter/ShelterBGM.ogg` (Vorbis, 약 0.7MB) |

### 2.1 구성

- **하프:** 4마디 코드 순환 **Dm(add9) → G(add9) → Am(9) → C(add9)** 를 16마디 내내 같은 8분음표 아르페지오로 반복한다. 도리안의 특징인 장조 IV(G, B 포함)가 신비한 색을 만든다.
- **플루트:** 하프는 고정하고 **멜로디만 바뀐다.** 4마디 프레이즈 4개.
  1. 제시 (마디 1~4) — 모티프 A–F–G–B, 중음역
  2. 응답 (마디 5~8) — 한 단계 위에서 같은 윤곽
  3. 고조 (마디 9~12) — 가장 넓은 음역(최고음 A5)
  4. 하강 (마디 13~16) — 음을 비우며 처음으로 복귀
- **뮤직박스:** 모티프를 한 옥타브 위로, 4마디 순환의 마지막 마디 3박부터 8분음표씩 들려주고 점 8분 에코를 붙인다.
- **현 드론:** D2 · A2 · D3 톱니파를 700Hz 로우패스로 깎아 깔고, 4마디 주기로 진폭이 숨 쉬듯 변한다.
- **공간감:** 길이 3.4초 홀 리버브(루프 꼬리를 앞으로 감는 원형 합성곱)를 30% 섞는다.

### 2.2 모티프 (다른 곡에서 재활용)

핵심 모티프는 **A – F – G – B**(타이틀 곡은 이를 B♭으로 바꿔 이어받는다) (D 도리안의 5도 → 3도 → 4도 → 6도). 쉘터 · 던전 등 다른 BGM을 만들 때 이 네 음의 윤곽을 변주하면 게임 전체에 통일감이 생긴다. 같은 모티프를 조성(프리지안 등)과 악기를 바꿔 쓰면 장면별 분위기 변화를 줄 수 있다.

---

## 3. 이음새 처리

- 지속음(드론)은 루프 길이에 정수 주기가 들어가는 주파수(`title.py`의 `loop_freq`)를 써서 위상을 맞춘다.
- 리버브 · 에코 꼬리와 마지막 마디 음의 여운은 루프 시작으로 감아 붙인다(원형 처리).
- `check.py`의 이음새 검사(점프 · 앞뒤 50ms RMS 비율)를 통과한다. OGG 변환 후에도 샘플 수가 2,352,000으로 같다.

## 4. 적용

| 단계 | 내용 |
|---|---|
| 에셋 | `Assets/06.Sounds/Shelter/ShelterBGM.ogg` (임포트: Compressed In Memory, Vorbis, Preload). 처음 `Title/TitleBGM.ogg`로 추가했던 파일을 GUID 유지한 채 옮김 |
| 씬 | `ShelterScene`에 `ShelterBGM` 오브젝트(`SceneBgmPlayer`, 루프, 페이드 0.5초) 추가 |
| 재생 코드 | 변경 없음 — `AudioManager.PlayBgm`의 루프 · 페이드(0.5초) 그대로. 씬을 떠날 때 `SceneBgmPlayer`가 BGM을 페이드아웃한다 |

## 5. 재현

```
cd Docs/tools/audiogen
.venv/Scripts/python.exe shelter.py   # Docs/drafts/audio/shelter_loop.wav 생성 + 루프 검증
```

같은 코드는 항상 같은 WAV를 만든다(이름 기반 시드). 시드 이름이나 난수 순서를 바꾸면 소리가 달라진다. 곡 이름을 타이틀에서 쉘터로 옮기면서도 시드 이름은 `title/...` 그대로 두었다(바꾸면 승인된 곡과 소리가 달라진다). 최종 OGG는 이 WAV를 Vorbis(libsndfile 기본 품질)로 변환한 것이다.

## 6. 남은 일

- 플레이 모드에서 쉘터 진입 시 루프 이음새와 음량(BGM 슬라이더 기준) 청취 확인. 쉘터 인트로 컷신 중 BGM을 어떻게 할지는 컷신 BGM API(`CutsceneContext.Audio`)와 함께 정한다.
- 합성음이라 실제 악기보다 인공적으로 들릴 수 있음. 필요하면 이후 사운드폰트나 직접 녹음 · DAW 작업물로 교체한다(모티프와 구조는 유지).
