## 2. 전체 흐름

```
[Q1 탈출 성공 → 쉘터 귀환]
  CS_SHELTER_COLLAPSE (Q1 완료 연출) → CS_Q1_DEBRIEF (그룬 보고, 무기 강화 해금)
        (대본: CS_Q1_WHETSTONE.md)
        ↓ 로나에게 E
  ① CS_Q2_BRIEFING  (쉘터, 20~30초) → SQ_MAIN_002 수주
        ↓
[Q2 출격: 쉘터 우측 통로 → E1 고정 스폰 → H2 홀]
  ② CS_ELENA_AMBUSH  (엘레나 1차 E키, 5~10초) → 매복 2웨이브
        ↓ 웨이브 소탕 → 다시 엘레나에게 E(결박 해제)
  ③ CS_ELENA_TELEPORT (5~10초) → 목표 "탈출"로 갱신
        ↓ Exit-C 또는 Exit-B에서 탈출 성공
[쉘터 귀환]
  ④ CS_Q2_PORTAL  (쉘터, 20~30초) → 포탈 점등, 이후 출격은 랜덤 스폰
```

### 2.1 쉘터 출격 입구 상태

쉘터의 던전 입구는 퀘스트 진행에 따라 4단계로 바뀐다. 씬 로드 시 영구 플래그로 상태를 정한다.

| 단계 | 조건 | 계단 자리 | 우측 통로 | 출격 방법 |
| :-: | :--- | :--- | :--- | :--- |
| 1 | `FLAG_SHELTER_COLLAPSE_DONE` 없음 | 계단 (정상) | 일반 통로 | 계단 |
| 2 | `FLAG_SHELTER_COLLAPSE_DONE` 있음, `FLAG_ELENA_RESCUED` 없음 | 무너진 계단 (`DungeonCollapsedStairs`) | 출격 입구 | 우측 통로 (E1 고정) |
| 3 | `FLAG_ELENA_RESCUED` 있음, `FLAG_Q2_PORTAL_DONE` 없음 | 불 꺼진 포탈 (게이트 타일로 만든 프레임) | 잔해로 막힘 | 없음 (④가 씬 시작 시 자동 재생되므로 이 상태에서 조작할 일은 없음) |
| 4 | `FLAG_Q2_PORTAL_DONE` 있음 | 켜진 포탈 | 잔해로 막힘 | 포탈 (E로 대화 → "들어간다" → `CS_TELEPORT_ENTER` 후 출격, 진입 구역 E1 · E2 · E3 랜덤) |

- 계단 자리 포탈은 쉘터의 기존 게이트 타일(`GateLintel`, `GateSill`)로 프레임을 만들고, 켜진 상태는 `ExitPortalFx_Front` 등 기존 FX를 재사용한다. 새 아트는 만들지 않는다.
- 우측 통로는 이미 씬에 있다. 2단계에서 출격 트리거만 붙인다.

## 3. 플래그 및 재생 조건

| 컷씬 | 씬 | 계기 | Required | Blocked | Completion | 저장 시점 |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| `CS_Q2_BRIEFING` | 쉘터 | 그룬 보고(`CS_Q1_DEBRIEF`) 뒤 로나 상호작용 (자동 재생 아님) | `FLAG_Q1_DEBRIEF_DONE` | `FLAG_Q2_BRIEFING_DONE` | `FLAG_Q2_BRIEFING_DONE`, `FLAG_Q2_ACCEPTED` + `SQ_MAIN_002` 수주 | 즉시 (쉘터) |
| `CS_ELENA_AMBUSH` | 던전 | 엘레나 1차 상호작용 | `FLAG_Q2_ACCEPTED` | `FLAG_ELENA_RESCUED`, `FLAG_ELENA_AMBUSH_SEEN` | `FLAG_ELENA_AMBUSH_SEEN` | **즉시 (런 중 예외)** |
| `CS_ELENA_TELEPORT` | 던전 | 결박 해제 (2차 E) | `FLAG_Q2_ACCEPTED` | `FLAG_ELENA_RESCUED`, `FLAG_ELENA_TELEPORT_SEEN` | `FLAG_ELENA_TELEPORT_SEEN` | **즉시 (런 중 예외)** |
| `CS_Q2_PORTAL` | 쉘터 | 씬 시작 자동 | `FLAG_ELENA_RESCUED` | `FLAG_Q2_PORTAL_DONE` | `FLAG_Q2_PORTAL_DONE` | 즉시 (쉘터) |

- **`_SEEN` 플래그는 런 중이어도 보류하지 않고 바로 저장한다.** cutscene-system-design 5장의 "런 중 컷씬은 탈출해야 저장" 규칙의 예외다. 컷씬 에셋에 "완료 플래그 즉시 저장" 옵션이 필요하다 (5장 갱신 참고).
- **구출 완료는 퀘스트가 처리한다.** 결박을 푸는 순간(2차 E) 씬 오브젝트가 `QuestService.RaiseRunFlag("H2_ELENA_FREED")`를 호출한다(컷씬 재생 여부와 무관). 탈출에 성공하면 `CompleteRun`이 `SQ_MAIN_002`를 완료하고, 해금 플래그 `FLAG_ELENA_RESCUED`를 추가한다. 사망하면 런 플래그가 사라지므로 다음 런에서 엘레나는 다시 결박된 상태다.
- **재시도 런의 대체 연출:** 씬 트리거는 `CanPlay`가 거짓이고 `_SEEN` 플래그가 있으면, 컷씬 대신 엘레나 머리 위에 말풍선 한 줄을 띄우고 같은 후속 처리(웨이브 시작 / 엘레나 퇴장)를 바로 실행한다. 조작은 잠그지 않는다.

## 4. ① CS_Q2_BRIEFING: 로나의 의뢰

| 항목 | 내용 |
| :--- | :--- |
| **길이** | 20~30초 |
| **등장 액터** | `Player`, `Lona` |
| **화면 요소** | 대사 + 감정 말풍선만. 지도 · 목표 위치 안내 · 회상 컷 없음 |
| **연결** | 그룬이 "로나가 할 말이 있다더군"이라며 보낸 뒤, 플레이어가 로나에게 말을 걸면 재생한다. 붕괴 컷씬은 엘레나를 언급하지 않으므로 01번 대사에서 엘레나를 처음 소개한다 |

### 4.1 비트

```
[1비트: 대면]
- 말을 건 자리에서 로나와 플레이어가 마주 선다 (FaceEachOther). 이동 · 카메라 마커 없음.
       ↓
[2비트: 엘레나 소개와 당위성]
- 로나가 엘레나가 누구이고 왜 필요한지 설명한다.
       ↓
[3비트: 진입 경로와 목표]
- 플레이어가 막힌 입구를 묻고, 로나가 우측 통로를 가리키며 E1 → H2 경로를 말한다. 카메라는 움직이지 않는다.
       ↓
[4비트: 의뢰 확정]
- 로나의 마지막 당부 후 페이드 아웃.
- 정리: 조작 · HUD 복구, FLAG_Q2_BRIEFING_DONE · FLAG_Q2_ACCEPTED 저장, SQ_MAIN_002 수주.
```

## 5. ② CS_ELENA_AMBUSH: 함정

| 항목 | 내용 |
| :--- | :--- |
| **길이** | 약 8~9초 |
| **등장 액터** | `Player`, `Elena` (결박 상태, `Elena_Kidnapped`), 1웨이브 적 (Normal 5 + Straight 2) |
| **계기** | H2 홀 중앙 기둥 사이의 엘레나에게 E키 (1차 상호작용) |
| **웨이브** | 스포너는 H2 홀 입구 여러 곳에 둔다. 컷씬이 보여주는 포위 방향과 실제 등장 위치가 같아야 한다 |

### 5.1 비트

```
[1비트: 경고 (~2초)]
- 엘레나 Shock 말풍선, 대사 "함정이에요!".
- 경보음 + 짧은 화면 흔들림.
- 이 순간 H2 입구들에서 1웨이브 적이 등장해 정지 상태로 선다.
       ↓
[2비트: 적 등장 지점 팬 (~2.5초)]
- 카메라가 가장 가까운 입구(AmbushEntrance1)로 팬해 적을 비춘다.
       ↓
[3비트: 포위 줌아웃 (~2.5초)]
- 카메라가 H2 중앙(AmbushCenter)으로 이동하며 줌아웃(CameraZoom)해 모든 입구의 적을 한 화면에 보여준다.
       ↓
[4비트: 복귀 (~1초)]
- 카메라가 플레이어에게 돌아오고 줌이 원래대로 돌아온다(CameraZoomReset).
- 정리: 적 정지 해제, 웨이브 시작 신호(Signal "AmbushStart"), FLAG_ELENA_AMBUSH_SEEN 즉시 저장.
```

### 5.2 대사 및 지문 테이블

| # | 화자 | 감정 말풍선 | 지문 및 카메라 연출 | 출력 대사 본문 | 시스템 이벤트 / SFX |
| :-: | :--- | :--- | :--- | :--- | :--- |
| 01 | 엘레나 | `Shock` | 플레이어가 다가오자 결박된 엘레나가 고개를 번쩍 든다. | "함정이에요! 뒤를 조심해요!" | `SFX_Alarm`, 화면 흔들림 (약), 1웨이브 등장 (정지) |
| - | - | - | 카메라 `AmbushEntrance1` 팬 → `AmbushCenter` 줌아웃 → 플레이어 복귀 | - | `Signal("AmbushStart")` |

### 5.3 재시도 런 대체

- 컷씬 없이 엘레나 머리 위 말풍선: **"함정이에요! 조심해요!"**
- 동시에 1웨이브가 바로 시작한다. 조작은 잠그지 않는다.

## 6. ③ CS_ELENA_TELEPORT: 먼저 갈게요

| 항목 | 내용 |
| :--- | :--- |
| **길이** | 약 7~8초 |
| **등장 액터** | `Player`, `Elena` |
| **계기** | 2웨이브 소탕 후 다시 엘레나에게 E (결박 해제, 홀드 없음) |
| **선행 처리** | 결박을 푸는 순간 `RaiseRunFlag("H2_ELENA_FREED")` (컷씬과 무관하게 항상) |

### 6.1 비트

```
[1비트: 해방 (~2.5초)]
- 밧줄이 풀리고 쓰러져 있던 엘레나가 일어선다 (Elena_GetUp: 사망 모습을 거꾸로 → Elena_Idle). 결박 중에는 Elena_Kidnapped(쓰러져 숨 쉬는 2프레임)를 반복 재생한다.
- 엘레나 Joy 말풍선, 감사 대사.
       ↓
[2비트: 전이 시전 (~3초)]
- 엘레나가 지팡이를 든다 (Elena_Cast). 발밑에 마법진 FX(SpawnMagicCircle).
- 전이 대사.
       ↓
[3비트: 퇴장 (~1.5초)]
- 흰 섬광(ScreenFader 점멸) 후 엘레나 숨김.
- 정리: 퀘스트 목표 "탈출 구역으로 이동"으로 갱신, FLAG_ELENA_TELEPORT_SEEN 즉시 저장. 카메라 이동 없음.
```

### 6.2 대사 및 지문 테이블

| # | 화자 | 감정 말풍선 | 지문 및 카메라 연출 | 출력 대사 본문 | 시스템 이벤트 / SFX |
| :-: | :--- | :--- | :--- | :--- | :--- |
| 01 | 엘레나 | `Joy` | 풀려난 엘레나가 손목을 주무르며 일어선다. | "고마워요! 마력이 조금 돌아왔어요." | `SFX_Rope_Release` |
| 02 | 엘레나 | - | 지팡이를 들어 올리자 발밑에 마법진이 떠오른다. | "전 먼저 쉘터로 건너갈게요. 당신도 어서 탈출하세요!" | `SpawnMagicCircle` FX, `SFX_Teleport_Charge` |
| - | - | - | 흰 섬광과 함께 엘레나가 사라진다. | - | 화면 점멸, `SFX_Teleport`, 목표 갱신 |

### 6.3 재시도 런 대체

- 컷씬 없이 엘레나 머리 위 말풍선: **"고마워요! 어서 탈출하세요!"**
- 말풍선이 끝나면 마법진 FX와 함께 엘레나가 사라지고 목표가 갱신된다. 조작은 잠그지 않는다.

## 7. ④ CS_Q2_PORTAL: 다시 열린 문

| 항목 | 내용 |
| :--- | :--- |
| **길이** | 20~30초 |
| **등장 액터** | `Player`, `Elena` |
| **계기** | `FLAG_ELENA_RESCUED` 보유, `FLAG_Q2_PORTAL_DONE` 미보유 상태로 쉘터 진입 (탈출 결과창 이후) |
| **무대** | 쉘터 2.1의 3단계 상태. 계단 자리에 불 꺼진 포탈 프레임, 우측 통로는 잔해로 막힘 |
| **설정** | 플레이어가 탈출하는 동안 엘레나가 무너진 계단 자리에 포탈 프레임을 다시 세웠다. 마법진은 언급하지 않는다 |

### 7.1 비트

```
[1비트: 재회 (~4초)]
- 페이드 인. 엘레나가 쉘터 중앙(ElenaCenter)에 서 있다.
- 플레이어는 귀환 위치에서 시작해 엘레나 앞(PlayerMeetElena)까지 자동으로 걷는다.
       ↓
[2비트: 포탈로 이동 (~6초)]
- 엘레나가 따라오라고 하고, 둘이 계단 자리 포탈 앞(PortalFront, PlayerPortal)으로 걸어간다. 카메라는 둘을 따라간다.
       ↓
[3비트: 점등 (~5초)]
- 불 꺼진 포탈 프레임을 비추는 구도 (PortalCamera).
```

## 8. Unity 연동 가이드

1. **신규 마커**
   - 쉘터: `LonaBrief`, `BriefCamera`, `ElenaCenter`, `PlayerMeetElena`, `PortalFront`, `PlayerPortal`, `PortalCamera`
   - H2 홀: `AmbushEntrance1`, `AmbushCenter` (+ 입구별 스포너 위치)
2. **쉘터 상태 오브젝트** (2.1 표)
   - 계단 자리 3상태(계단 / 무너진 계단 / 포탈 꺼짐 · 켜짐)와 우측 통로 2상태(열림 / 잔해)를 씬 로드 시 플래그로 켜고 끈다.
   - 포탈 점등은 ④ 컷씬 안에서 `Signal("PortalIgnite")`로 교체한다.
3. **엘레나 액터**
   - 던전: `NPC_Elena`를 결박 상태(`Elena_Kidnapped`)로 H2 중앙에 배치. 1차 상호작용 = 매복, 웨이브 소탕 후 2차 상호작용(E) = 바로 결박 해제.
   - 쉘터: `FLAG_ELENA_RESCUED` 이후 `ElenaCenter`에 상주.
4. **선행 조건 (구현 의존성)**
   - 컷씬 시스템 정식 이관 (cutscene-system-design 11장 5단계). 정식 씬이 샌드박스 스크립트를 참조할 수 없다.
   - `QuestService`를 `GameManager`에 연결 (quest-system-implementation-plan 2단계). `SQ_MAIN_002` 퀘스트 에셋 생성.
   - 컷씬 중 적 정지 (cutscene-system-design 7.3). ②의 정지된 적 노출에 필요.
   - 던전 컷씬 "완료 플래그 즉시 저장" 옵션 (3장).
   - 재시도 런의 말풍선 한 줄을 컷씬 밖에서 띄울 방법 (현재 말풍선은 컷씬 대사 데이터로만 동작).
