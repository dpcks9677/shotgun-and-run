# [QA/Playtest] Shotgun and Run 지인 QA 통합 정리

> **프로젝트:** Shotgun and Run  
> **작성일:** 2026-10-14  
> **QA 대상:** 현재 3명의 팀원이 주변 지인에게 받은 플레이테스트 및 QA 피드백  
> **정리 기준:** 팀원별 → 지인별 → 테스트 케이스/검증 포인트, 버그 리포트, 희망 사항 및 개선 의견

## 1. 문서 작성 기준

- 원문에서 명확한 재현 절차가 없는 항목은 `테스트 케이스/검증 포인트`가 아니라 `희망 사항/개선 의견`으로 분류했다.
- 동일한 내용이 여러 지인에게서 나온 경우 한 항목으로 통합하고, 해당 항목의 출처를 함께 표시했다.

### 2.3 주요 개선 분야

1. **진행 및 목표 인지성:** 퀘스트 목록, 퀘스트 아이템, 제작대, 탈출 포탈, 로비 상호작용 대상의 상태를 더 명확하게 표현할 필요가 있다.
2. **전투 피드백:** 탄환의 거리별 위력, 반동, 피격 및 공격 전조를 시각적으로 전달할 필요가 있다.
3. **튜토리얼 및 입력 안내:** 대화 넘기기, NPC 상호작용, 가방, 대시, 장전 등 주요 입력을 플레이 중 명확하게 안내해야 한다.
4. **레벨 및 AI 안정성:** 낙석·창고 콜리전, 오브젝트 끼임, 전투 구역 이탈, 고블린 어그로, Straight의 벽 타기, 초반 및 습격 난이도를 점검해야 한다.
5. **진행 흐름 및 편의 기능:** 퀘스트 목적지의 순서, 게임 종료 방법, 자동·일괄 장전, 전투 후 결과 화면의 정보 가독성을 보완해야 한다.
6. **무기·로비 피드백:** 무기 획득과 조준 방식을 직관적으로 만들고, 로비의 상호작용 대상과 NPC 정보를 쉽게 확인할 수 있도록 보완해야 한다.

# 4. 팀원별 상세 QA 내용

## 4.1 예찬

예찬 팀원의 QA는 기존 첨부 문서의 내용을 기준으로 정리했다. 첨부 문서에는 예찬-A/B/C의 피드백과 함께 조준각 역전, 컷씬 스킵 등 버그 리포트가 포함되어 있다.

### 4.1.1 예찬-A

#### 간략 요약

아트와 연출의 완성도, 대화창 가독성, 전투 VFX, 조명, 해상도 대응에 대한 개선 의견이 중심이다. 코어 게임플레이 루프에 대해서는 긍정적인 평가가 있었다.

#### 테스트 케이스/검증 포인트

- **[Y-A-TC01] 가변 해상도 UI 검증:** 16:9, 16:10, 21:9 환경에서 UI 앵커와 픽셀 퍼펙트 카메라가 정상적으로 유지되는지 확인한다.
- **[Y-A-TC02] 던전 조명 가독성 검증:** 기본 조도를 낮춘 상태에서 플레이어, 적, 상호작용 대상, 총구 화염이 구분되는지 확인한다. 기본 조도 하향은 조치 완료 상태다.

#### 버그 리포트

- 보고된 재현성 버그는 없다.

#### 희망 사항 및 개선 의견

- **[Y-A-01] 대화창 화자 포트레이트 추가**
  - **분야:** UI / 아트 / 내러티브
  - **내용:** 쉘터와 퀘스트 대화에서 화자의 캐릭터성이 잘 전달되도록 대화창 좌우에 스탠딩 일러스트 또는 감정별 얼굴 포트레이트를 표시한다.

- **[Y-A-02] 코어 게임플레이 방향 유지**
  - **분야:** 게임 디자인 / 총평
  - **내용:** 2D 탑다운 슈팅과 익스트랙션 규칙의 조합이 안정적으로 작동하고 장르적 재미가 분명하다는 긍정 평가다. 핵심 루프의 방향성은 유지하는 것이 좋다.

- **[Y-A-03] 원거리 적의 공격 템포와 투사체 속도 조정**
  - **분야:** 전투 밸런스
  - **내용:** 활을 사용하는 적의 화살 속도가 총기류처럼 빨라 회피가 어렵다. 투사체 속도를 낮추고, 시위를 당기는 동작 등 발사 전조를 추가해 회피 타이밍을 학습할 수 있게 한다.

- **[Y-A-04] 프레임 기반 전투 VFX 도입**
  - **분야:** 아트 / VFX
  - **내용:** 현재의 단일 텍스처 확대 후 페이드아웃 방식은 폭발과 타격감이 약하다. 폭발, 파편, 충격파를 프레임 단위 스프라이트 시트 애니메이션으로 교체한다.

- **[Y-A-05] 대화창 레이아웃과 폰트 가독성 개선**
  - **분야:** UI / 가독성
  - **내용:** 여백에 비해 글자가 작고 배치가 익숙하지 않아 읽기 어렵다. 대화창 레이아웃을 재설계하고 폰트 크기와 시인성을 높인다.

- **[Y-A-06] 던전 조명 연출 개선**
  - **분야:** 그래픽 / 환경 연출
  - **내용:** 던전의 기본 조도는 낮추고, 횃불·발광체·총구 화염을 중심으로 포인트 광원을 배치해 음산한 분위기를 강화한다.
  - **조치 현황:** 던전 맵의 기본 조도 하향은 완료되었으며, 포인트 광원 디테일은 추가 작업이 필요하다.

- **[Y-A-07] Rich Text 기반 대사 연출**
  - **분야:** UI / 연출
  - **내용:** TextMeshPro Rich Text 또는 Text Animator를 이용해 핵심 단어의 볼드·색상 강조, 물결·흔들림 효과, 타이핑 사운드 동기화를 적용한다.

- **[Y-A-08] 가변 해상도와 멀티플랫폼 대응**
  - **분야:** 시스템 / 테크
  - **내용:** 다양한 모니터 종횡비에서 UI와 픽셀 퍼펙트 카메라가 정상 작동하도록 Canvas Scaler와 입력 파이프라인을 점검한다.

### 4.1.2 예찬-B

#### 간략 요약

던전 파밍 동선과 동적 난이도, 퀘스트 목적지 안내, 인벤토리 편의성, 대시 조작 정책에 대한 의견이 있었다. 초근접 조준과 강제 종료 후 컷씬 스킵이라는 P0 수준의 버그도 보고되었다.

#### 테스트 케이스/검증 포인트

- **[Y-B-TC01] 튜토리얼 유황 획득 필수 조건 검증**
  - 유황을 획득하지 않고 다음 통로를 통과할 수 있는지 확인한다.
  - 유황이 필수 아이템이면 미획득 상태에서 진행이 막히거나, 상자 개봉 시 자동 획득되는지 확인한다.

#### 버그 리포트

- **[Y-B-BUG01] 초근접 조준 시 총구 방향과 탄환 발사각이 180도 역전됨**
  - **심각도:** P0 / 긴급
  - **분야:** 전투 조준
  - **재현 조건:** 마우스 커서를 플레이어 본체 중심 또는 피봇에 매우 가깝게 둔 상태에서 조준 및 발사한다.
  - **기대 결과:** 총구가 향한 방향으로 탄환이 발사된다.
  - **실제 결과:** 총구 방향과 반대 방향으로 탄환이 발사된다.
  - **추정 원인:** 커서와 플레이어 피봇 간 거리가 0에 가까울 때의 `Atan2` 계산, 스프라이트 플립, 총구 트랜스폼 회전의 동기화 문제 가능성이 있다.
  - **개선 방향:** 일정 반경 안에 조준 데드존을 두어 이전 조준각을 유지하고, 발사 벡터를 총구 트랜스폼과 단일 기준으로 동기화한다.

- **[Y-B-BUG02] 컷씬 중 강제 종료 후 스토리 시퀀스가 스킵됨**
  - **심각도:** P0 / 긴급
  - **분야:** 컷씬 / 세이브 시스템
  - **재현 조건:** 튜토리얼에서 박쥐와 고블린이 등장하는 인카운터 컷씬 중 Alt+F4 등으로 강제 종료한 뒤 재실행한다.
  - **기대 결과:** 컷씬 또는 전투가 완료되지 않은 상태로 복구된다.
  - **실제 결과:** 컷씬과 전투가 완료된 것으로 처리되어 스토리가 스킵된다.
  - **추정 원인:** 컷씬 시작 시점에 퀘스트 또는 시퀀스 완료 플래그가 먼저 저장되는 문제다.
  - **개선 방향:** 몬스터 처치와 연출 종료가 모두 확인된 시점에만 완료 플래그를 저장하고, 저장 트랜잭션을 원자적으로 처리한다.

#### 희망 사항 및 개선 의견

- **[Y-B-01] 북쪽 구역 편중 파밍 개선**
  - **분야:** 레벨 디자인 / 경제
  - **내용:** 북쪽 구역만 파밍해도 짧은 시간 안에 물품을 모두 확보하고 탈출할 수 있는 동선이 발생한다. 고급 상자와 퀘스트 요소를 동·서·남 구역에도 분산하고, 잠금 게이트나 레버 등 탐험 기믹을 추가한다.

- **[Y-B-02] 체류 시간 기반 동적 난이도**
  - **분야:** 시스템 / 난이도 곡선
  - **내용:** 던전에 오래 머무를수록 몬스터 이동속도와 스폰 밀도가 점진적으로 상승하도록 해 제한 시간과 독가스 압박에 맞는 탈출 긴장감을 강화한다.

- **[Y-B-03] 대시 조작 정책 확정**
  - **분야:** 조작계 / 전투 디자인
  - **내용:** 마우스 우클릭 대시와 스페이스바 대시의 역할이 혼재되어 있으므로 하나의 기본 조작을 확정하거나 옵션에서 선택할 수 있게 한다. 두 방식의 차이는 튜토리얼에서 설명한다.

- **[Y-B-04] 대장장이 그룬 퀘스트 목적지 명확화**
  - **분야:** 퀘스트 / 내러티브
  - **내용:** 의뢰가 쉘터 내부 작업인지 던전 출격인지 불명확하다. 던전에 진입해 특정 구역으로 이동해야 한다는 내용을 대사에 직접 명시하고 퀘스트 마커를 제공한다.

- **[Y-B-05] 인벤토리 아이템 버리기 기능**
  - **분야:** 인벤토리 / QoL
  - **내용:** 가방이 가득 찼을 때 불필요한 아이템을 버릴 수 있도록 드래그 앤 드롭 또는 컨텍스트 메뉴 기반의 Drop 기능을 추가한다.

### 4.1.3 예찬-C

#### 간략 요약

대시 성능, 필드 몬스터의 추적 적극성, 대형 몬스터 AI, 공격 전조, 루팅 속도, 일괄 획득, 퀘스트 HUD에 대한 의견이 있었다. 대시 이동 거리와 대형 몬스터 AI 개선은 전투 체감에 직접적인 영향을 주는 항목이다.

#### 테스트 케이스/검증 포인트

- 별도 재현 절차가 있는 버그는 원문에 없었다. 다만 아래 버그 리포트의 대형 몬스터 AI 이상은 전투 상황별 재현 테스트가 필요하다.

#### 버그 리포트

- **[Y-C-BUG01] 대형 근접 몬스터가 플레이어 전방에서 후퇴함**
  - **분야:** 몬스터 AI / 패스파인딩
  - **재현 조건:** 플레이어가 대형 근접 몬스터의 전방에 위치한 상태에서 몬스터의 추적 및 공격 행동을 관찰한다.
  - **기대 결과:** 몬스터가 플레이어에게 접근해 공격한다.
  - **실제 결과:** 플레이어가 바로 앞에 있어도 뒤로 물러나는 비정상 행동이 발생한다.
  - **개선 방향:** 후퇴 조건과 패스파인딩을 수정하고, 이동속도·공격 사거리·돌진·부채꼴 공격·슈퍼아머 등 대형 몬스터에 맞는 위협 패턴을 재설계한다.

#### 희망 사항 및 개선 의견

- **[Y-C-01] 대시 이동 거리 상향**
  - **분야:** 플레이어 조작 / 전투 기동성
  - **내용:** 약 1.5타일의 대시 거리는 공격 범위를 벗어나기에 짧다. 2.5~3타일 정도로 늘리거나 순간 가속을 추가해 회피기로서의 효용을 높인다.
  - **조치 현황:** 대시 중 무적 시간은 상향 조정되었으며, 이동 거리 추가 상향은 후속 검토가 필요하다.

- **[Y-C-02] 필드 기본 배치 몬스터의 어그로 강화**
  - **분야:** 몬스터 AI / 전투 템포
  - **내용:** 포탈 스폰 적에 비해 필드 배치 몬스터의 인식 반경과 추적 적극성이 낮다. 시야각과 순찰에서 추격으로 전환되는 조건을 완화한다.

- **[Y-C-03] 근접 공격 전조 통일**
  - **분야:** 전투 피드백 / VFX
  - **내용:** 원거리 공격처럼 근접 공격에도 붉은색 공격 범위 표시를 제공해 피격 판정과 회피 타이밍을 납득할 수 있게 한다.

- **[Y-C-04] 전리품 상자 개봉 시간 단축**
  - **분야:** 루팅 / QoL
  - **내용:** 상자 개봉 채널링 시간이 파밍 템포를 저하시키므로 즉시 개봉 또는 0.2초 미만으로 단축한다. 개봉 애니메이션과 입력 피드백도 함께 점검해 체감 지연을 줄인다.

- **[Y-C-05] E키 홀드 상자 자동 획득**
  - **분야:** 루팅 / UI
  - **내용:** E키를 일정 시간 꾹 누르면 상자를 열면서 획득 가능한 아이템을 자동으로 인벤토리에 넣을 수 있게 한다. 획득 결과는 인벤토리에서 확인할 수 있어야 하며, 수용량 부족 상태도 알려야 한다.

- **[Y-C-06] 인게임 상시 퀘스트 트래커**
  - **분야:** UI / 퀘스트
  - **내용:** 현재 진행 중인 퀘스트 목표와 진행도, 예를 들어 `정밀 숫돌 회수 0/1`을 화면에 상시 표시한다.

- **[Y-C-07] 코어 게임플레이 루프 유지**
  - **분야:** 게임 디자인 / 총평
  - **내용:** 조작감과 전투의 기본 골격이 갖춰져 있어 킬링타임 액션 게임으로서 잠재력이 있다는 긍정 평가다. 세부 폴리싱을 통해 완성도를 높이는 방향이 적절하다.

## 4.2 민석

민석의 피드백은 동일한 내용이 여러 지인에게서 나온 경우 하나로 취합했다. 공통 항목의 출처에는 `민석-A, 민석-B` 또는 `민석-A, 민석-C`를 함께 표시했다.

### 4.2.1 민석-A·민석-B 공통

#### 간략 요약

퀵 슬롯 선택 상태, 맵 및 탈출 포탈, 퀘스트 수주 내역을 확인하는 UI가 충분히 눈에 들어오지 않는다는 의견이다.

#### 테스트 케이스/검증 포인트

- **[M-AB-TC01] 퀵 슬롯 선택 상태 확인**
  - 아이템을 선택한 뒤 선택된 슬롯이 비선택 슬롯과 즉시 구분되는지 확인한다.
  - 전투 중 시선을 오래 두지 않아도 선택 상태를 파악할 수 있어야 한다.

- **[M-AB-TC02] 맵 및 탈출 포탈 탐색 확인**
  - 처음 방문한 맵에서 탈출 포탈의 위치를 제한된 시간 안에 파악할 수 있는지 확인한다.
  - 포탈이 활성화되기 전과 후의 위치·상태가 명확히 구분되는지 확인한다.

- **[M-AB-TC03] 퀘스트 수주 내역 확인**
  - 퀘스트를 수주한 뒤 현재 진행 중인 퀘스트 목록과 목표를 다시 열람할 수 있는지 확인한다.

#### 버그 리포트

- 별도 재현 절차가 있는 공통 버그는 보고되지 않았다.

#### 희망 사항 및 개선 의견

- **[M-AB-01] 퀵 슬롯 선택 아이템의 가시성 강화**
  - **분야:** UI
  - **출처:** 민석-A, 민석-B
  - **개선 내용:** 선택된 퀵 슬롯에 외곽선, 확대, 색상 변화, 배경 강조 등 명확한 선택 상태 표시를 추가한다.

- **[M-AB-02] 맵과 탈출 포탈의 위치 인지성 개선**
  - **분야:** 게임플레이 / 레벨 디자인
  - **출처:** 민석-A, 민석-B
  - **개선 내용:** 맵 구조를 파악하기 어렵고 탈출 포탈 위치를 찾기 힘들다. 미니맵 표시, 포탈 아이콘, 방향 안내, 탐험에 따른 맵 공개 등의 방식을 검토한다.

- **[M-AB-03] 퀘스트 수주 내역 UI 추가**
  - **분야:** 게임플레이 / UI
  - **출처:** 민석-A, 민석-B, 민석-D, 민석-E
  - **개선 내용:** 현재 수주한 퀘스트, 목표, 진행도를 확인할 수 있는 퀘스트 목록 또는 메뉴를 제공한다. 대장간에서 받은 의뢰처럼 퀘스트가 생성되었을 때 화면에 표시되는 목표·의뢰 마커도 함께 제공한다.

### 4.2.2 민석-A

#### 간략 요약

쉘터 NPC 대사의 다양성, 창고와 기관실의 레벨 안정성, 기관실 퀘스트의 연출, 대시 HUD 인지성에 대한 의견이다.

#### 테스트 케이스/검증 포인트

- **[M-A-TC01] 기관실 이동 안정성 확인**
  - 기관실 퀘스트 수행 중 주요 통로와 오브젝트 주변을 이동한다.
  - 플레이어가 벽, 오브젝트, 문 사이에 끼이거나 진행 불가 상태가 되지 않아야 한다.

- **[M-A-TC02] 창고 충돌 영역 확인**
  - 창고 내부 및 외곽을 이동하며 오브젝트를 통과하거나 의도하지 않은 방향으로 빠져나갈 수 있는지 확인한다.

#### 버그 리포트

- **[M-A-BUG01] 기관실에서 플레이어가 끼이는 문제**
  - **분야:** 레벨 디자인 / 콜리전
  - **재현 조건:** 기관실 내부에서 벽, 문, 설비 주변을 이동하며 퀘스트를 수행한다.
  - **실제 결과:** 플레이어가 특정 지점에 끼이는 현상이 반복적으로 발생한다.
  - **개선 방향:** 해당 지점의 Collider 중첩, 통로 폭, 이동 제한 영역을 점검하고 탈출 가능한 보정 로직을 추가한다.

- **[M-A-BUG02] 창고 콜리전 누락 또는 보강 필요**
  - **분야:** 레벨 디자인 / 콜리전
  - **내용:** 창고에 플레이어 이동을 제한해야 하는 충돌 영역이 부족해 보인다. 통과 가능 영역과 차단 영역을 명확하게 나누고, 오브젝트별 Collider를 검증한다.

#### 희망 사항 및 개선 의견

- **[M-A-01] 쉘터 경비병 대사 다양화**
  - **분야:** 게임플레이 / 내러티브
  - **내용:** 쉘터의 경비병이 모두 같은 말을 하기보다 경비병별로 서로 다른 대사나 상황별 대사를 제공해 공간의 생동감을 높인다.

- **[M-A-02] 기관실 퀘스트의 문 닫힘 연출 추가**
  - **분야:** 게임플레이 / 사운드 / VFX
  - **내용:** 기관실 퀘스트에서 문이 닫히는 시점에 문 닫힘 사운드와 시각 효과를 추가해 진행 상태와 공간 변화를 명확하게 전달한다.

### 4.2.3 민석-B

#### 간략 요약

초반 몬스터 난이도, 제작대 인지성, 퀘스트 아이템 표시, 대시와 장전 키 배치에 대한 의견이다.

#### 테스트 케이스/검증 포인트

- **[M-B-TC01] 초반 전투 대응 가능성 확인**
  - 게임 초반 장비와 체력 상태로 첫 몬스터를 상대한다.
  - 적의 공격을 인지하고 회피·반격할 시간이 충분한지, 첫 교전이 학습 가능한 난이도인지 확인한다.

- **[M-B-TC02] 제작대 인지성 확인**
  - 제작대에 대한 별도 설명 없이 초반 지역을 탐색한다.
  - 플레이어가 제작대의 기능과 상호작용 가능 여부를 알아차릴 수 있는지 확인한다.

#### 버그 리포트

- 현재 원문에서 확정적인 재현 버그는 보고되지 않았다.

#### 희망 사항 및 개선 의견

- **[M-B-01] 초반 몬스터 난이도 하향**
  - **분야:** 레벨 디자인 / 전투 밸런스
  - **내용:** 초반 몬스터의 공격력, 체력, 이동속도 또는 공격 빈도를 낮춰 플레이어가 기본 조작과 게임 규칙을 익힐 시간을 확보한다.

- **[M-B-02] 제작대 튜토리얼 또는 하이라이트 추가**
  - **분야:** 게임플레이 / 튜토리얼 / UI
  - **내용:** 제작대에 퀘스트, 튜토리얼, 상호작용 아이콘, 외곽선 또는 화면 하이라이트를 제공해 별도 설명 없이도 기능을 인식할 수 있게 한다.

- **[M-B-03] 퀘스트 아이템 시각적 구분 강화**
  - **분야:** 게임플레이 / UI / 아이템 아트
  - **내용:** 퀘스트 아이템의 스프라이트에 외곽선, 색상, 아이콘, 빛나는 효과 등을 추가해 일반 아이템과 쉽게 구분되도록 한다.

- **[M-B-04] 대시와 장전 키 배치 재검토**
  - **분야:** 조작계
  - **출처:** 민석-B, 민석-D
  - **내용:** 오른쪽 이동 키와 R키를 동시에 누르기 어렵고 튜토리얼에 스페이스바 대시 안내가 누락되어 있다. 스페이스바를 대시, 마우스 우클릭을 장전으로 사용하는 방식 등 대체 조작을 검토하고 키 변경 옵션과 실제 조작 안내를 제공한다.

### 4.2.4 민석-C

#### 간략 요약

탄환의 거리별 위력과 반동, 탈출 포탈 상태, 체력 감소 단위, HUD 배치, 탄띠 업그레이드, 상자 설계에 대한 전투·UI 피드백이다.

#### 테스트 케이스/검증 포인트

- **[M-C-TC01] 탄환 거리별 피드백 확인**
  - 동일한 적을 대상으로 가까운 거리와 먼 거리에서 발사한다.
  - 거리에 따라 피해량이 감소한다면 탄환 굵기, 색상, 궤적 또는 타격 효과에서도 그 차이가 인지되는지 확인한다.

- **[M-C-TC02] 탈출 포탈 활성화 상태 확인**
  - 포탈이 비활성 상태에서 활성 상태로 바뀌는 시점을 관찰한다.
  - 제한시간 색상 변화만으로도 의미가 전달되는지, 아이콘 등 추가 표시가 필요한지 확인한다.

- **[M-C-TC03] HUD 위치 인지성 확인**
  - 실제 전투 중 대시 보유량과 탄창 정보를 찾아본다.
  - 화면 모서리를 확인하지 않아도 필요한 정보를 빠르게 인식할 수 있는지 확인한다.

#### 버그 리포트

- 확정적인 코드 결함으로 분류할 재현 버그는 보고되지 않았다. 다만 HUD 미인지와 포탈 상태 오인지는 사용성 검증을 통해 우선 확인할 필요가 있다.

#### 희망 사항 및 개선 의견

- **[M-C-01] 탄환 거리별 위력 저하를 시각화**
  - **분야:** 게임플레이 / 전투 피드백
  - **내용:** 탄환이 멀어질수록 굵기를 얇게 하거나 궤적·타격 효과를 변화시켜 거리별 데미지 감소가 플레이어에게 보이도록 한다.

- **[M-C-02] 탈출 포탈 활성화 상태를 아이콘으로 표시**
  - **분야:** UI / 게임플레이
  - **내용:** 제한시간이 파란색으로 변하는 것만으로는 의미 파악이 어렵다. 포탈 이모티콘, 활성화 아이콘, 상태 문구 등을 함께 표시한다.

- **[M-C-03] 반 칸 단위 체력 감소 검토**
  - **분야:** 전투 밸런스 / 긴장감
  - **내용:** 하트가 반 칸 단위로 감소하도록 해 피격의 세밀함과 긴장감을 높인다. 특히 박쥐의 공격을 반 칸 피해로 조정하는 방안을 검토한다.

- **[M-AC-01] HUD 위치 재배치 및 정보 집중**
  - **분야:** UI / 몰입감
  - **출처:** 민석-A, 민석-C, 민석-D
  - **내용:** HUD가 화면 꼭짓점마다 흩어져 시선이 분산된다. 대시와 탄창은 플레이어 옆이나 아래에 배치하고, 하트와 퀵 슬롯도 서로 가까운 위치에 배치한다. 실제 플레이 중 좌측 하단의 대시 보유량을 인지하지 못한 사례가 있어 위치와 강조를 함께 개선하며, 대시 아이콘도 동작을 연상할 수 있는 직관적인 픽토그램으로 교체하는 방안을 검토한다.

- **[M-C-04] 반동 이펙트 추가**
  - **분야:** 게임플레이 / VFX
  - **내용:** 발사 시 화면 흔들림, 총기 반동 애니메이션, 총구 움직임, 탄피 또는 짧은 후퇴 효과 등을 추가해 발사 감각을 강화한다.

- **[M-C-05] 탄띠 파츠 업그레이드 효과 명확화**
  - **분야:** 성장 시스템 / UI
  - **내용:** 다른 파츠는 업그레이드 시 증가 능력치가 직관적으로 표시되지만, 탄띠는 1레벨에서 갑자기 관통 탄환 효과가 생겨 이후 효과를 예측하기 어렵다. 레벨별 효과와 다음 업그레이드 효과를 명확히 표시한다.

- **[M-C-06] 상자 크기에 따른 용량·상호작용 시간·보상 차등화**
  - **분야:** 레벨 디자인 / 루팅 / 경제
  - **내용:** 상자 크기별로 수용 용량과 상호작용 시간을 다르게 설정하고, 한 칸짜리 상자에서 더 좋은 재료가 나오는 등 기대감을 형성하는 규칙을 도입한다. 플레이어가 경험적으로 상자 크기와 보상을 연결할 수 있어야 한다.

### 4.2.5 민석-D·민석-E 공통

#### 간략 요약

게임 진행 중 메뉴와 일시정지 기능, 퀘스트 정보를 확인하는 방법이 부족하다는 의견이다. ESC를 통한 옵션 접근과 게임 흐름을 방해하지 않는 메뉴 전환을 제공할 필요가 있다.

#### 테스트 케이스/검증 포인트

- **[M-DE-TC01] 게임 진행 중 메뉴 접근 확인**
  - 탐험 또는 전투 중 ESC를 누른다.
  - 게임이 일시정지되고 옵션·메뉴 화면으로 이동할 수 있어야 하며, 메뉴에서 복귀했을 때 진행 상태가 유지되어야 한다.

- **[M-DE-TC02] 퀘스트 정보 접근 확인**
  - 퀘스트를 수주한 뒤 메뉴 또는 HUD에서 퀘스트 제목, 목표, 목적지를 확인한다.
  - 대장간 의뢰처럼 새 퀘스트가 시작되는 즉시 관련 정보가 표시되어야 한다.

#### 버그 리포트

- 별도 재현 절차가 있는 공통 버그는 보고되지 않았다. ESC 메뉴 접근은 예정된 기능으로 전달된 항목이다.

#### 희망 사항 및 개선 의견

- **[M-DE-01] ESC 메뉴 및 일시정지 기능 추가**
  - **분야:** UI / 시스템
  - **출처:** 민석-D, 민석-E, 추가 QA
  - **개선 내용:** 게임 진행 중 ESC로 일시정지하고 설정, 메인 화면, 게임 종료 메뉴로 이동할 수 있게 한다. 메뉴 진입 중 적과 플레이어의 시간이 함께 멈추고, 복귀 시 기존 진행 상태가 유지되어야 한다.

### 4.2.6 민석-D

#### 간략 요약

낙석과 이동 충돌, UI 배치와 인지성, 전투 구역과 적 어그로, 튜토리얼·퀘스트 흐름, 장전 편의 기능, 결과 화면과 게임 종료 방법에 대한 피드백이다.

#### 테스트 케이스/검증 포인트

- **[M-D-TC01] 시작 구간 낙석 충돌 확인**
  - 게임 시작 시 큰 돌과 작은 돌이 떨어지는 장면을 관찰하고, 플레이어 또는 주변 오브젝트와 충돌하는지 확인한다.
  - 장식용 낙석과 위험 요소를 구분하고, 위험한 돌이라면 시각적 연출과 실제 충돌 판정이 일치해야 한다.

- **[M-D-TC02] 대각선 벽 이동 확인**
  - 플레이어가 벽을 대각선 방향으로 따라 이동한다.
  - 계단처럼 걸리거나 이동 속도가 불규칙하게 끊기지 않고 벽면을 따라 자연스럽게 미끄러져야 한다.

- **[M-D-TC03] 전투 구역 이탈 및 적 어그로 확인**
  - 전투 존에 진입한 뒤 외부로 이탈을 시도한다.
  - 전투 존의 경계와 이탈 제한이 의도된 규칙에 따라 작동하고, 적 어그로가 비정상적으로 해제되어 전투를 쉽게 회피할 수 없어야 한다.

- **[M-D-TC04] 고블린 탐지 및 어그로 확인**
  - 고블린 주변을 이동하며 탐지 거리 안으로 접근한다.
  - 특정 경로를 모두 지나간 뒤에야 반응하지 않고, 설정된 탐지 거리와 시야 조건에서 즉시 적절하게 반응해야 한다.

- **[M-D-TC05] 튜토리얼 및 퀘스트 흐름 확인**
  - 튜토리얼 존에서 야영장으로 이동하고, 게시판·대장간 퀘스트를 순서대로 진행한다.
  - 튜토리얼 대사와 실제 전투 결과가 모순되지 않아야 하며, 게시판과 대장간의 목적지 안내 순서가 서로 뒤바뀌지 않아야 한다.

- **[M-D-TC06] 결과 화면 정보 가독성 확인**
  - 캐릭터가 사망한 뒤 결과 화면을 확인한다.
  - 항목별 폰트 크기와 획득 경험치 표기가 일관되고, 수량을 쉽게 읽을 수 있어야 한다.

#### 버그 리포트

- **[M-D-BUG01] 시작 구간 낙석에 충돌 판정이 없음**
  - **분야:** 레벨 디자인 / 콜리전 / 연출
  - **재현 조건:** 게임 시작 시 떨어지는 큰 돌과 작은 돌 주변으로 플레이어를 이동한다.
  - **실제 결과:** 위험해 보이는 낙석에 실제 충돌 판정이 없어 연출과 플레이 규칙 사이에 차이가 느껴진다.
  - **개선 방향:** 위험 요소로 사용할 낙석에는 Collider와 피해·넉백 등 판정을 추가하거나, 장식용 낙석임을 명확히 보여주는 연출로 조정한다.

- **[M-D-BUG02] 대각선 벽 이동 시 계단처럼 걸리는 현상**
  - **분야:** 플레이어 이동 / 콜리전
  - **재현 조건:** 벽을 대각선 방향으로 따라 이동하거나 책상·벽 모서리를 향해 이동한다.
  - **실제 결과:** 플레이어가 벽면을 따라 미끄러지지 않고 계단처럼 걸리거나 이동이 끊긴다.
  - **개선 방향:** 플레이어 Collider와 벽 Collider의 모서리·마찰 설정을 점검하고, 벽면 투영 이동 또는 충돌 보정으로 자연스럽게 이동하도록 수정한다.

- **[M-D-BUG03] 전투 존 밖에서 적 어그로가 해제되어 전투를 회피할 수 있음**
  - **분야:** 레벨 디자인 / 적 AI
  - **재현 조건:** 전투 존에 진입해 적을 유인한 뒤 전투 존 밖으로 이동한다.
  - **실제 결과:** 적 어그로가 풀려 안전하게 전투를 중단할 수 있다.
  - **개선 방향:** 전투 존 진입 시 벽 또는 봉쇄 연출을 활성화하거나, 전투가 끝날 때까지 적이 추적을 유지하도록 전투 상태를 보강한다.

- **[M-D-BUG04] 튜토리얼 대사와 실제 전투 결과의 흐름 불일치**
  - **분야:** 튜토리얼 / 내러티브 / 레벨 디자인
  - **재현 조건:** 튜토리얼 존을 벗어날 때 도망쳐야 한다는 대사를 확인한 뒤 야영장에 도착한다.
  - **실제 결과:** 플레이어가 야영장에 도착하기 전 적을 모두 처치할 수 있어 대사와 실제 플레이 흐름이 어색하게 느껴진다.
  - **개선 방향:** 야영장의 기사와 궁수가 전투를 지원하게 하거나, 튜토리얼 존의 적 구성·체력·진행 조건을 조정해 대사와 플레이 결과를 일치시킨다.

- **[M-D-BUG05] 게시판과 대장간 퀘스트 안내 순서가 뒤바뀜**
  - **분야:** 퀘스트 / 진행 흐름
  - **재현 조건:** 대장간 방문 후 게시판과 대장간 관련 안내를 순서대로 확인한다.
  - **실제 결과:** 대장간에 먼저 가라는 안내 후 게시판으로 유도되거나, 대장간 방문 시 게시판을 먼저 가라고 안내해 목적지 흐름이 혼란스럽다.
  - **개선 방향:** 퀘스트 선행 조건과 목적지 갱신 시점을 정리하고, 게시판 → 대장간의 의도된 순서가 대사·마커·목표 UI에 동일하게 표시되도록 수정한다.

- **[M-D-BUG06] 고블린의 탐지 및 반응이 늦음**
  - **분야:** 적 AI / 탐지
  - **재현 조건:** 고블린 주변을 지나가며 경로를 따라 이동한다.
  - **실제 결과:** 가까이 접근해도 바로 어그로가 끌리지 않고 특정 경로를 모두 지나야 플레이어에게 반응한다.
  - **개선 방향:** 탐지 거리, 시야 판정, 경로상 장애물, 탐지 갱신 주기를 점검하고 플레이어가 인지 가능한 범위에서 일관되게 반응하도록 조정한다.

#### 희망 사항 및 개선 의견

- **[M-D-01] 전리품과 가방 UI 위치 조정**
  - **분야:** UI / 인벤토리
  - **개선 내용:** 전리품 UI와 가방 UI가 너무 멀리 떨어져 있어 시선 이동이 불편하다. 두 UI를 가까운 위치에 배치하거나 동일한 정보 영역에서 연속적으로 확인할 수 있게 한다.

- **[M-D-02] 탄약 소진 시 자동 장전**
  - **분야:** 게임플레이 / 조작 편의
  - **개선 내용:** 현재 탄약을 모두 사용하면 별도 입력 없이 자동으로 장전을 시작해 전투 흐름이 끊기지 않도록 한다. 자동 장전 중 취소·회피 가능 여부도 함께 정의한다.

- **[M-D-03] 창고 사방 상호작용 지원**
  - **분야:** 레벨 디자인 / 상호작용
  - **개선 내용:** 창고 정면에서만 열 수 있는 대신, 플레이어가 접근 가능한 사방에서 상호작용할 수 있게 해 접근 방향에 따른 불편을 줄인다.

- **[M-D-04] 창고와 벽의 외형 구분**
  - **분야:** 레벨 디자인 / 아트
  - **개선 내용:** 창고와 동일하게 생긴 에셋이 벽으로도 사용되어 상호작용 대상을 혼동할 수 있다. 벽 전용 디자인이나 색상·윤곽을 사용해 창고와 시각적으로 구분한다.

- **[M-D-05] 근거리 게이지샷 위력 상향 검토**
  - **분야:** 전투 밸런스 / 무기 체감
  - **개선 내용:** 샷건의 특성을 살리기 위해 0거리에서 게이지샷의 펠릿을 모두 맞히면 고블린이나 박쥐 정도는 한 번에 처치할 수 있는 수준을 검토한다.

- **[M-D-06] 대시 아이콘 직관성 개선**
  - **분야:** UI / HUD
  - **개선 내용:** 좌하단 대시 개수 표시가 직관적이지 않다. 사람이 스르륵 이동하는 느낌의 픽토그램처럼 대시 행동을 연상할 수 있는 아이콘과 남은 횟수 표시를 사용한다.

- **[M-D-07] 결과 화면 폰트 크기 통일**
  - **분야:** UI / 결과 화면
  - **개선 내용:** 사망 후 결과창의 폰트 크기를 항목 간 일관되게 맞추고, 특히 획득 경험치 수량을 다른 정보와 비슷한 크기로 표시한다.

- **[M-D-08] 게임 종료 방법 안내**
  - **분야:** UI / 시스템
  - **개선 내용:** ESC 메뉴 또는 타이틀 화면에서 게임 종료, 설정, 메인 화면 이동 방법을 제공하고 해당 기능을 쉽게 찾을 수 있게 한다.

- **[M-D-09] 장전 타이밍 입력에 따른 일괄 장전**
  - **분야:** 게임플레이 / 장전 시스템
  - **개선 내용:** 재장전 중 타이밍에 맞춰 장전 키를 입력하면 남은 탄환을 한 번에 장전하는 기능을 검토한다. 성공 판정 구간, 실패 시 기본 장전 진행, 사운드·UI 피드백을 함께 설계한다.

### 4.2.7 민석-E

#### 간략 요약

ESC 메뉴 접근, 대시 중 오브젝트 끼임과 탈출 방법, 맵 규모, 퀘스트 창에 대한 추가 피드백이다.

#### 테스트 케이스/검증 포인트

- **[M-E-TC01] 오브젝트를 향한 대시 이동 확인**
  - 로비의 책상 등 오브젝트를 향해 한 칸 및 두 칸 거리에서 대시한다.
  - 대시 종료 후 플레이어가 오브젝트와 벽 사이에 끼이지 않고 정상적으로 이동할 수 있어야 하며, 상·하 방향의 빈틈으로 맵을 이탈할 수 없어야 한다.

- **[M-E-TC02] 끼임 상태 탈출 확인**
  - 오브젝트 사이에 끼이는 상황을 재현한다.
  - 충돌 박스와 대시 종료 위치가 의도대로 작동하고, 끼임이 발생하더라도 ESC 메뉴 진입 또는 별도 복구 동작으로 플레이를 재개할 수 있어야 한다.

#### 버그 리포트

- **[M-E-BUG01] 오브젝트를 향한 대시 후 끼임 발생**
  - **분야:** 플레이어 이동 / 콜리전
  - **재현 조건:** 로비에서 오브젝트를 향해 한 칸 또는 두 칸 거리에서 상·하 방향으로 대시한다.
  - **실제 결과:** 플레이어가 오브젝트와 겹치거나 상·하 빈틈으로 대시해 맵 밖으로 빠져나갈 수 있다.
  - **개선 방향:** 오브젝트와 플레이어의 충돌 박스, 대시 종료 위치 보정, 상·하 양측 차단, 주변 빈 공간 검사와 끼임 탈출 로직을 점검한다.

#### 희망 사항 및 개선 의견

- **[M-E-01] 전체 맵 규모 축소 검토**
  - **분야:** 레벨 디자인
  - **개선 내용:** 전체 맵이 크게 느껴져 이동과 목표 탐색이 길어질 수 있다. 이동 시간과 콘텐츠 밀도를 확인한 뒤, 우선순위가 낮은 선택 항목으로 맵 축소 또는 동선 압축을 검토한다.

## 4.3 성훈

성훈의 원문에는 지인별 구분이 없으므로 모든 항목을 `성훈-A`로 정리했다.

### 4.3.1 성훈-A

#### 간략 요약

튜토리얼 진행 중 필요한 입력과 목표를 충분히 알기 어렵고, 대시·가방·상호작용·대화 진행 키 안내가 부족하다는 의견이 중심이다. Straight의 이동 및 벽 충돌 행동, 고블린 탐지 거리, 습격 난이도 등 적 AI와 난이도 조정 의견도 포함되어 있다.

#### 테스트 케이스/검증 포인트

- **[S-A-TC01] 총 획득 직후 튜토리얼 진행 검증**
  - 총을 획득한 직후 이동과 발사를 시도한다.
  - 이동이 의도적으로 제한되는 구간이라면, 발사가 필요한 구간이라는 안내가 표시되어야 한다.
  - 의도하지 않은 이동 잠금이라면 진행을 막는 버그로 수정한다.

- **[S-A-TC02] 튜토리얼 입력 안내 검증**
  - 튜토리얼에서 대화 넘기기, NPC 상호작용, 가방 열기, 대시, 장전 등 입력을 처음 접한다.
  - 각 기능을 실제로 사용해야 하는 시점에 해당 키 안내가 노출되는지 확인한다.

- **[S-A-TC03] 튜토리얼 중 설정창 접근 검증**
  - 튜토리얼 진행 중 ESC를 누른다.
  - 설정창이 정상적으로 열리고, 복귀 후 튜토리얼 진행 상태가 유지되는지 확인한다.

- **[S-A-TC04] 쉘터 대시 정보 확인**
  - 쉘터에서 대시를 사용할 수 있는지 확인한다.
  - 사용할 수 있다면 탐험 지역과 동일하게 대시 UI가 표시되는지 확인한다.

#### 버그 리포트

- **[S-A-BUG01] 총 획득 후 이동이 제한되어 진행 의도를 알기 어려움**
  - **분야:** 튜토리얼 / 진행성
  - **내용:** 총 획득 후 플레이어가 움직이지 못한다. 해당 상태가 의도된 연출인지, 조작 잠금 버그인지 판별이 필요하다.
  - **개선 방향:** 발사가 필요한 구간이라면 화면에 발사 안내를 명시하고, 의도하지 않은 잠금이라면 입력 제한을 해제한다.

- **[S-A-BUG02] Straight가 벽을 장시간 타는 현상**
  - **분야:** 적 AI / 충돌 처리
  - **내용:** Straight가 벽에 부딪힌 뒤 상당히 긴 시간 동안 벽을 타며 정상적으로 플레이어를 추적하지 못한다.
  - **개선 방향:** 벽 충돌 시 idle 또는 기절 상태로 전환하거나, 경로 재탐색과 충돌 탈출 로직을 추가한다.

#### 희망 사항 및 개선 의견

- **[S-A-01] 튜토리얼 대화 넘기기 입력 추가**
  - **분야:** UI / 튜토리얼
  - **내용:** 스페이스바 또는 마우스 클릭으로 튜토리얼 대화를 넘길 수 있게 한다.

- **[S-A-02] 대시 키 변경**
  - **분야:** 게임플레이 / 조작계
  - **내용:** 현재 대시 키가 사용하기 불편하므로 다른 키로 변경하거나 사용자가 직접 지정할 수 있게 한다.

- **[S-A-03] 튜토리얼 상자에서 가방 단축키 안내**
  - **분야:** 튜토리얼 / 인벤토리
  - **내용:** 상자를 연 직후 가방을 열어 아이템을 확인해야 한다면, 가방 단축키를 같은 화면이나 안내 문구로 알려준다.

- **[S-A-04] NPC 상호작용 및 대화 진행 키 명확화**
  - **분야:** UI / 튜토리얼
  - **내용:** NPC와 상호작용하는 키와 대화 다음 단계로 넘어가는 키를 화면에 분명하게 표시한다.

- **[S-A-05] Straight 이동 속도 하향**
  - **분야:** 적 밸런스
  - **내용:** Straight의 이동 속도가 빨라 대응하기 어렵다. 초반 등장 시 이동속도를 낮추거나 공격 전조와 회피 시간을 함께 제공한다.

- **[S-A-06] 쉘터 대시 UI 표시**
  - **분야:** 쉘터 / UI
  - **내용:** 쉘터에서도 대시를 사용할 수 있으므로 대시 보유량 또는 쿨다운 UI를 표시해 기능을 인지할 수 있게 한다.

- **[S-A-07] 탐험에 따른 미니맵 공개**
  - **분야:** UI / 레벨 디자인
  - **내용:** 처음부터 전체 맵을 보여주기보다 플레이어가 탐험한 영역을 중심으로 미니맵이 점차 공개되도록 한다.

- **[S-A-08] 피격 후 무적 시간 연장**
  - **분야:** 플레이어 밸런스
  - **내용:** 피격 직후 연속 공격을 받는 상황을 줄이기 위해 피격 후 무적 시간을 소폭 늘린다.

- **[S-A-09] 고블린 탐지 거리 확대**
  - **분야:** 적 AI / 전투 템포
  - **내용:** 고블린이 플레이어를 인식하는 거리를 늘려 적의 존재감과 교전 빈도를 높인다. 확대 후에는 기습 난이도가 과도해지지 않는지 함께 검증한다.

- **[S-A-10] 습격 난이도 하향**
  - **분야:** 게임플레이 / 난이도
  - **내용:** 습격 상황의 적 수, 공격 빈도, 적 스펙 또는 진행 속도를 조정해 대응 가능한 난이도로 낮춘다.

## 4.4 추가 QA 피드백

> 작성자가 별도로 지정되지 않은 추가 QA 희망사항이다. 기존 항목과 겹치는 내용은 기존 ID를 보강하고, 새로운 내용은 `QA-N` ID로 관리한다.

#### 간략 요약

무기 획득과 조준 피드백이 과도하거나 직관적이지 않고, 로비에서 상호작용 대상과 NPC 정보를 파악하기 어렵다는 의견이다. 오브젝트 대시를 통한 끼임 및 맵 이탈 가능성, 캐릭터 방향별 스프라이트, 자동 저장과 남은 적 수 표시도 개선되면 좋을 것 같다.

#### 확인 포인트

- **[QA-N-TC01] 무기 획득 피드백 확인**
  - 무기를 획득할 때 화면 전체를 가리는 섬광이 발생하는지 확인한다.
  - 간단한 무기 설명 창 또는 무기 강조 효과만으로 획득 결과와 무기 종류를 인지할 수 있으면 좋을 것 같다.

- **[QA-N-TC02] 조준점 가독성 확인**
  - 총을 든 상태에서 마우스를 화면 가장자리까지 이동하며 조준한다.
  - 마우스 포인터의 위치를 따라가는 느낌 대신 화면 내 조준점으로 발사 방향을 예측할 수 있으면 좋을 것 같다.

- **[QA-N-TC03] 로비 상호작용 안내 확인**
  - 로비의 모든 상호작용 가능한 오브젝트와 NPC에 접근한다.
  - 대화, 열기 등 대상에 맞는 상호작용 안내가 일관되게 표시되면 좋을 것 같다.

- **[QA-N-TC04] 로비 오브젝트 대시 콜리전 확인**
  - 오브젝트에서 한 칸 및 두 칸 떨어진 위치에서 상·하 방향으로 대시한다.
  - 오브젝트와 겹치거나 상·하 빈틈으로 맵 밖으로 빠져나가는 일이 막히면 좋을 것 같다. 기존 `M-E-BUG01` 검증을 보강한다.

- **[QA-N-TC05] NPC 이름 표시 확인**
  - 로비의 NPC를 화면에서 확인한다.
  - 캐릭터 아래에 이름이 표시되어 NPC를 구분할 수 있으면 좋을 것 같다.

- **[QA-N-TC06] 상자 개봉 속도 확인**
  - 여러 종류의 상자를 연속으로 개봉한다.
  - 입력 후 실제 개봉까지의 대기 시간이 길게 느껴지지 않고, 개봉 완료 시점이 명확하면 좋을 것 같다. `Y-C-04`를 보강한다.

- **[QA-N-TC07] E키 홀드 자동 획득 확인**
  - 상자 앞에서 E키를 꾹 눌러 상자를 연다.
  - 개봉과 동시에 획득 가능한 아이템이 자동으로 인벤토리에 들어가고, 획득 결과를 인벤토리에서 확인할 수 있으면 좋을 것 같다. `Y-C-05`를 보강한다.

- **[QA-N-TC08] 캐릭터 상하 방향 스프라이트 확인**
  - 캐릭터가 위·아래 방향으로 이동하거나 조준하는 상황을 확인한다.
  - 방향에 맞는 스프라이트가 표시되어 좌우 스프라이트를 재사용한 것처럼 보이지 않으면 좋을 것 같다.

- **[QA-N-TC09] ESC 메뉴 흐름 확인**
  - 로비와 전투 중 ESC를 누른다.
  - 설정, 메인 화면 이동, 게임 종료 기능에 접근할 수 있고, 메뉴에서 복귀했을 때 진행 상태가 유지되면 좋을 것 같다. `M-DE-01`, `M-D-08`을 보강한다.

- **[QA-N-TC10] 자동 저장 안내 확인**
  - 자동 저장이 발생하는 시점의 화면을 확인한다.
  - 자동 저장 중이거나 완료되었다는 문구가 짧고 명확하게 표시되어 저장 여부를 알 수 있으면 좋을 것 같다.

- **[QA-N-TC11] 잔여 적 수 표시 위치 확인**
  - 전투 중 남은 적 수 표시를 확인한다.
  - 중앙 시야를 가리지 않도록 오른쪽 등 보조 위치에 작게 표시하거나, 게임 흐름을 방해한다면 표시를 없애도 좋을 것 같다.

#### 기존 항목 보강

- **[Y-C-04] 전리품 상자 개봉 시간 단축:** 개봉 속도가 느리게 느껴지는 체감 지연과 입력·애니메이션 피드백을 함께 개선하면 좋을 것 같다.
- **[Y-C-05] 상자 일괄 획득 단축키:** E키 홀드로 개봉과 자동 획득을 연결하고, 결과를 인벤토리에서 확인할 수 있으면 좋을 것 같다.
- **[M-E-BUG01] 오브젝트를 향한 대시 후 끼임 발생:** 로비 오브젝트의 한 칸·두 칸 거리 및 상·하 방향 대시에서 맵 이탈이 일어나지 않도록 보완하면 좋을 것 같다.
- **[M-DE-01], [M-D-08] ESC 메뉴 및 게임 종료:** ESC에서 설정, 메인 화면 이동, 게임 종료까지 접근할 수 있는 흐름이면 좋을 것 같다.

#### 희망 사항 및 개선 의견

- **[QA-N-01] 무기 획득 시 설명 또는 강조 효과 추가**
  - **분야:** UI / 전투 피드백
  - **내용:** 무기 획득 시 눈부신 섬광 대신 짧은 무기 설명 창을 보여주거나, 획득한 무기를 잠시 강조해 종류와 획득 사실을 전달하면 좋을 것 같다.

- **[QA-N-02] 마우스 포인터 대신 조준점 사용**
  - **분야:** 조작계 / 전투 UI
  - **내용:** 총을 들었을 때 화면 가장자리까지 이동하는 마우스 포인터를 중심 조준점으로 대체하거나, 포인터와 발사 방향의 관계를 명확한 조준점으로 보완하면 좋을 것 같다.

- **[QA-N-03] 로비 상호작용 프롬프트 추가**
  - **분야:** 로비 / UI / 상호작용
  - **내용:** 상호작용 가능한 모든 오브젝트와 NPC에 접근하면 `대화`, `열기` 등 대상에 맞는 안내 문구가 표시되면 좋을 것 같다.

- **[QA-N-04] 로비 NPC 이름 표시**
  - **분야:** 로비 / UI / 내러티브
  - **내용:** NPC 캐릭터 아래에 이름을 표시해 대화 상대와 역할을 쉽게 구분할 수 있으면 좋을 것 같다.

- **[QA-N-05] 상하 방향 캐릭터 스프라이트 추가**
  - **분야:** 아트 / 플레이어 가독성
  - **내용:** 캐릭터가 위와 아래를 바라볼 때도 방향에 맞는 스프라이트가 표시되도록 추가하면 좋을 것 같다.

- **[QA-N-06] 자동 저장 상태 문구 추가**
  - **분야:** UI / 시스템
  - **내용:** 자동 저장 시점에 짧은 상태 문구를 표시해 저장이 진행되거나 완료되었음을 알려주면 좋을 것 같다.

- **[QA-N-07] 잔여 적 수 표시 위치 조정**
  - **분야:** UI / 전투 가독성
  - **내용:** `몇 마리 남았습니다` 문구를 중앙에서 오른쪽 등 시야를 덜 가리는 위치로 옮기고 크기를 줄이면 좋을 것 같다. 정보가 시야를 방해하면 표시를 없애도 좋을 것 같다.

# 5. 후속 QA 권장 순서

1. **진행을 막는 버그 우선 확인**
   - 예찬-B의 초근접 조준 역전, 컷씬 강제 종료 후 스킵
   - 민석-A의 기관실 끼임과 창고 콜리전
   - 성훈-A의 총 획득 후 이동 제한 및 Straight 벽 충돌

2. **퀘스트와 튜토리얼 정보 구조 정리**
   - 퀘스트 목록 및 진행도
   - 퀘스트 아이템 강조
   - 제작대와 NPC 상호작용 안내
   - 대시·장전·가방·대화 진행 키 안내
   - 로비 오브젝트의 대화·열기 안내와 NPC 이름 표시

3. **맵과 HUD 가시성 개선**
   - 탈출 포탈 아이콘과 활성화 상태
   - 맵 공개 방식과 미니맵
   - 퀵 슬롯 선택 강조
   - 대시·탄창·체력 정보의 위치 재배치
   - 조준점과 잔여 적 수 표시 위치

4. **전투 밸런스와 피드백 조정**
   - 초반 몬스터와 습격 난이도
   - Straight와 고블린의 AI·탐지 거리
   - 대시 거리와 무적 시간
   - 탄환 거리별 피드백, 반동, 근접 공격 전조

5. **루팅과 성장 시스템 개선**
   - 상자 개봉 시간과 일괄 획득
   - 상자 크기별 보상 규칙
   - 탄띠 파츠의 레벨별 효과 표시
   - 인벤토리 아이템 버리기
   - 자동 저장 상태 문구와 무기 획득 설명·강조 효과

### 상태 정의

- `Open`: 아직 수정되지 않음
- `In Progress`: 수정 중
- `Fixed`: 수정 완료, 재테스트 전
- `Verified`: QA 재테스트에서 정상 확인
- `Won't Fix`: 의도된 동작 또는 우선순위상 수정하지 않음
