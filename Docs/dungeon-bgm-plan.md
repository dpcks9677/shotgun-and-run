# 던전 BGM 제작 · 연동 계획서 (다크 앰비언트 + 전투 스템)

> **작성 일자:** 2026-10-13  
> **상태:** 오디오 제작 · 승인 완료(PR 1: 에셋 + 도구 + 계획서), 재생 코드 구현 · 리뷰 완료(PR 2), 플레이 모드 확인 대기  
> **범위:** 던전(Run) 안에서 재생되는 적응형 BGM의 오디오 제작(1~2단계), 재생 코드(4단계)  
> **관련 문서:** [cutscene-system-design.md](cutscene-system-design.md) (컷씬 BGM API) / 제작 도구 `Docs/tools/audiogen/` (이 계획서로 신설)

## 1. 목표

- 던전 안에서 **스산한 다크 앰비언트**가 항상 깔려 있다. 물 떨어지는 소리, 바스락거림, 먼 금속 울림이 간간이 들린다.
- **습격 경고 · 습격 시작 · 적 추격**이 일어나면 그 위에 드럼과 다크 아날로그 신스 리프(+서브 베이스)가 **자연스럽게 얹힌다.** 전투가 끝나면 다시 앰비언트만 남는다.
- **어느 구간에서 켜도 박자가 맞고, 루프 이음새가 들리지 않는다.**

**제외:** 튜토리얼 던전 BGM(보류 중), 쉘터·타이틀 BGM, 컷씬 BGM 변경, 전투 SFX 변경.

## 3. 결정 사항

### 3.1 구조

| 레이어 | 내용 | 재생 |
|---|---|---|
| 앰비언트 베드 | 드론 · 바람 · 저음 질감 + 매 마디 저음 심장박동 맥박(lub-dub, 2026-10-13 평온 구간 단조로움 보완, 키트 드럼은 전투 신호 구분을 위해 쓰지 않음) | 항상 루프 |
| 원샷 SFX 풀 | 물방울 · 바스락 · 먼 금속 울림 · 돌 부스럭임 · 바람 한 줄기, **5종 × 변형 2~3개** | 6~18초 랜덤 간격, 피치 ±· 팬 랜덤. 전투 중 자동 중단. SFX 그룹 |
| 드럼 스템 | 하프타임 드럼 + 심장박동 플로어탐 | 전투 신호에 페이드인 |
| 신스 스템 | 필터 엔벨로프가 열리는 아날로그 신스 플럭 리프 + 서브 (2026-10-13 합성 일렉기타가 가짜처럼 들려 교체) | 강한 전투 신호에 페이드인 |
| 습격 스템 | 저음 브라스 롱 스웰 · 스탭(근음 + 5도 + 옥타브) + 서스테인 디스토션 파워코드 질감 + 디스토션 베이스 8분 처킹(홀수 마디 끝 갤럽) + 더블타임 습격 드럼(킥이 처킹과 락된 16분 더블 킥 · 16분 하이햇과 32분 롤 · 구간별로 밀도가 오르는 스네어 · 탐 롤). 합성 기타 처킹은 가짜 같다는 평가로, 아르페지오 신스는 청취 후 제외(`raid.py`의 `GUITAR_CHUG` 상수로 기타 폴백 가능)(킥 매 박 · 스네어 박 사이 · 16분 하이햇 · 탐 롤). 템포는 75 BPM 그대로이고 음표 밀도와 백비트로 150 BPM처럼 들리게 한다 (2026-10-13 속도감 보강) | 습격 시작에만 페이드인. 켜지면 신스를 약 -3dB 낮춰 저역 뭉침을 막는다 |

앰비언트 · 드럼 · 신스 · 습격 네 루프는 **길이와 시작점이 완전히 같다**(3.2). 항상 동시에 재생을 시작해 두고 볼륨만 올리내리므로 어느 시점에 켜도 박자가 맞는다.

### 3.2 음악 규격

- **75 BPM · 4/4 · 32마디.** 1박 0.8초, 1마디 3.2초, 루프 **102.4초.**
- 샘플레이트 44100 Hz → 루프 길이 **4,515,840 샘플**(정수). 모든 루프 파일이 이 길이와 정확히 같아야 한다.
- **D 마이너 · 프리지안.** 드론은 근음 + 완전5도. 8마디 단위로 4구간이고, 평온 구간이 정적이어 피로하지 않도록 **근음을 4마디(약 13초)마다 옮긴다**(2026-10-13 결정, 습격 사이 평온 구간이 약 2분 50초라 단일 드론이 길다는 지적). 근음은 리프의 D와 협화하는 음(D · B♭ · G · A · C)을 쓰고, 부딪히는 E♭은 B 구간에서만 쓴다.

| 구간 | 마디(1기반) | 앰비언트 근음(5도) | 앰비언트 색 | 신스 리프의 근음 |
|---|---|---|---|---|
| A | 1~8 | D(A) 1~4 → B♭(F) 5~8 | 드론만 | D5 |
| B | 9~16 | E♭(B♭) | E♭ 패드가 천천히 차올랐다 빠짐 | D5 → E♭5 (구간 끝 4마디) |
| A′ | 17~24 | D(A) 17~20 → G(D) 21~24 | A와 같되 저역 럼블 질감 변화 | D5 |
| C | 25~32 | C(G) 25~28 → B♭(F) 29~31 → D(A) 32 | B♭ 패드 | C5 → B♭5 → A5 → D5 (4마디 순환) |

- 근음이 바뀌는 지점은 반 마디(약 1.6초) 크로스페이드로 잇는다. 마디 32의 D는 루프 시작의 D로 이어진다.
- 습격이 정확히 180초 간격이면 습격 시작은 루프 마디 25 · 17.5 · 9.75 · 2 근처(1~4차)에 떨어진다. 어느 곳이든 스템과 협화하도록 근음을 골랐다.

- 앰비언트의 모든 LFO · 스웰 주기는 루프 길이의 약수(1·2·4·8·16·32마디)로 맞춘다.
- 이음새: **잔향 · 딜레이 꼬리는 루프 시작으로 감아 넣는다**(원형 합성). 끝에서 잘리지 않고 앞에서 이어진다.
- **드럼:** 킥 1박 · 3박 뒤쪽, 스네어 3박(하프타임), 8마디마다 마지막 박에 탐 필인. 심벌은 쓰지 않는다(앰비언트 위에서 지저분해짐).
- 신호가 와서 켜질 때 박자가 맞도록 모든 스템은 1마디 첫 박에 아무 소리가 없어도 같은 시작점을 가진다.

### 3.3 전환 규칙

2026-10-13 사용자 결정으로 단계를 4개로 단순화했다. 단계는 누적된다(아래 단계는 위 단계 위에 얹힌다). 이전의 "추격 적 N마리" 규칙은 제거했다.

| 단계 | 조건 | 켜지는 레이어 |
|---|---|---|
| 0 일반 | 기본 | 앰비언트(+ 맥박) + 원샷 SFX |
| 1 적 인지 | **적이 카메라 안에 있다** | + 드럼 |
| 2 습격 임박 | `WarningEvent`(습격 10초 전) ~ `RaidEvent` | + 신스 (드럼 유지) |
| 3 습격 중 | `RaidEvent` 이후 | + 습격 스템(풀 다이나믹). 신스는 -6dB로 낮춰 저역을 비운다 |

- **켜기:** 신호가 오면 **다음 박 경계**(최대 0.8초 뒤)에서 시작해 2~4초에 걸쳐 페이드인. (스템은 이미 같은 위치에서 무음으로 돌고 있으므로 볼륨만 올린다.)
- **끄기(드럼):** 적이 카메라에서 모두 벗어난 뒤 **5초 대기 → 4초 페이드아웃.**
- **끄기(습격 스템 · 신스):** 습격 종료 시점에 맞춰 빠진다(아래). 습격 → 신스 → 드럼 순으로 빠진다.
- **카메라 안 적 판정(2026-10-13 결정):** 카메라는 플레이어를 따라가고(`PlayerCameraFollow`, 오프셋 (0,0,-10), 맵 가장자리 고정 없음) 크기가 고정이라, **플레이어 중심의 카메라 크기 사각형(여유 약 1유닛)** 안에 적이 있는지로 판정한다(원이 아니라 사각형 — 16:9). 적 레지스트리가 없으므로 0.2초마다 `Physics2D.OverlapBox`(적 레이어 `Enemy` · `EnemyBody`)로 확인한다. 적 코드는 수정하지 않는다.
- **습격 종료(2026-10-13 결정):** 습격으로 스폰된 적이 모두 죽으면 종료. 코드에 종료 신호가 없으므로 `EnemyRaidSpawner.EnemySpawned`(이미 공개된 이벤트)를 구독해 습격 적을 모으고, "수집된 적이 모두 사라졌고 새 스폰이 없는 상태가 약 3초 유지"되면 종료로 본다(스폰이 0.7초 간격 · 포탈 대기가 있어 스폰 중 빈틈을 건너뛰기 위함). 스포너 코드는 수정하지 않는다. 습격이 겹쳐도(다음 습격이 먼저 도착) 전부 사라질 때까지 풀 다이나믹이 유지된다.
- 전투 중에는 원샷 SFX 풀이 쉰다.
- **수명:** `RunStarted`에 앰비언트 페이드인, `RunEnded`에 전부 페이드아웃. Run 상태에만 적용(튜토리얼 제외).

## 5. 재생 코드 설계 개요 (4단계)

- 앰비언트 · 드럼 · 신스 · 습격 네 `AudioSource`에 **같은 `AudioSettings.dspTime`으로 `PlayScheduled`**를 걸어 시작점을 맞춘다. 드럼 · 신스 · 습격은 볼륨 0으로 시작한다.
- 켜기 · 끄기는 `AudioSource.volume`(또는 믹서 파라미터)을 코루틴 · 보간으로 움직인다. 켜기 시작 시각은 `(dspTime - 시작 시각)`을 박 길이(0.8초)로 올림해 다음 박 경계에 맞춘다.
- 원샷 풀은 타이머로 클립 · 피치 · 팬을 랜덤 선택해 `PlayOneShot`한다. 전투 상태일 때 타이머를 멈춘다.
- 신호 연결: `RaidTimer.WarningEvent` · `RaidEvent`, 적 추격 수는 FSM의 `ChaseState` 진입 · 이탈을 센다. **추격 수를 어디서 세는지**(기존 이벤트 재사용 가능 여부)는 4단계 착수 때 조사한다.
- 기존 `AudioManager`의 BGM 경로(컷씬)와 충돌하지 않도록 컷씬 재생 중에는 던전 BGM을 낮추거나 멈출지 4단계에서 확인한다.
- 위치는 `AudioManager` 확장 또는 별도 컴포넌트 중 **기존 코드를 재사용하는 쪽**으로 한다. 단일 용도의 추상화는 만들지 않는다.
