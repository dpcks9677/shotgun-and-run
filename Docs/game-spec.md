## 1. 개요

| 항목 | 내용 |
|---|---|
| 장르 | 탑다운 슈터 + 익스트랙션 슈터 |
| 레퍼런스 | Enter the Gungeon (탑다운 조작·전투감) |
| 시점 | 2D 탑다운 |
| 플레이 인원 | 싱글 전용 |
| 맵 | 정적으로 만든 큰 맵 1장 (절차적 생성 없음) |
| 무기 | 샷건 1종 고정, 파츠 강화로 성장 |
| 성장 축 | ① 무기 파츠 강화 (재료) ② 플레이어 레벨 (XP) |
| 개발 범위 | 프로토타입(전투) → 알파-1: 스테이지 1개 완성 (12장) |

### 1.1 난이도 목표: 중급
- 초반(무강화)에는 **조심스럽게 플레이**해야 하는 수준. 무리하게 교전하면 위험
- **파츠 강화로 강해지는 체감**이 확실해야 함. 같은 존을 강화 후 다시 돌면 눈에 띄게 수월
- 성장 목표 기간: 무기 전 파츠 최대 약 21~22런, 플레이어 최대 레벨 약 25런

## 3. 게임 흐름

### 3.1 핵심 루프
```
[쉘터] 무기 강화 · 플레이어 레벨업 · 소모품 제작/장착 · 퀘스트 수주
   ↓
[출격] 스폰 → 파밍·전투 → 탈출
   ├ 탈출 성공 → 가방 재료 창고 저장 + 런 XP 전액 + 탈출 보너스 + 퀘스트 판정 → [쉘터]
   └ 사망      → 가방 재료·장착 소모품 소실, 런 XP 30%만 유지 → [쉘터]
```

### 3.2 런 흐름
```
[쉘터] 준비
   ↓
[스폰] 스폰 포인트 3곳 중 1곳 랜덤 (메인 스토리 Q1 · Q2 진행 중에는 E1 고정, Q2 완료 후 랜덤 해금 — quest-story-concept.md)
   ↓
[탐색] 커넥터 이동 · 순찰 적과 소규모 전투 · 커넥터 상자
   ↓                          ↑
[메인 존] 수비대 소탕 · 존 상자 루팅 (오래 머물면 추가 웨이브)   (반복, 선택)
          구역 정화 퀘스트가 있으면 오브젝트로 디펜스 웨이브
   ↓
[탈출 구역] (런 시작 3분 후 활성) 구역 안에서 10초 대기 → 탈출 성공 → [쉘터]

※ 어느 단계에서든 사망 → [쉘터]
※ 전 구간: 2분 20초 ~ 3분마다 주기 습격 (4.6)
※ 12분 초과 → 페널티 상태 (3.4)
```

### 3.3 런 결과

| 결과 | 가방 재료 | 장착 소모품 | 런 XP | 퀘스트 |
|---|---|---|---|---|
| 탈출 성공 | 쉘터 복귀 시 창고에 자동 누계 (7.5) | 남은 것 유지 | 100% + 탈출 보너스 50% | 달성분 인정 |
| 사망 | 전부 소실 | 전부 소실 | 30%만 유지 | 인정 안 됨 (퀘스트는 유지) |

### 3.4 런 제한 시간
- 기본 **12분**
- 초과 시 페널티: **최대 체력 절반 (소수점 버림)** + **이동속도 −20% (배율 0.8)**
  - 예: 최대 체력 5칸 → 2칸, 6칸 → 3칸, 7칸 → 3칸, 8칸 → 4칸
  - 이동속도: 기본 6.5u/초 → 5.2u/초
  - 현재 체력이 새 최대치보다 높으면 최대치로 낮춤. 회복 소모품은 **새 최대치까지 사용 가능**
- 탈출 활성화(3분)부터 제한 시간(12분)까지 **9분**이 실질적인 파밍 시간
- 목표: 던전에 오래 머물지 않고 적당히 탐사한 뒤 탈출하게 만듦. 9:20 이후에 오는 4회차 주기 습격(4.6)이 막바지 압박 역할

## 4. 맵

### 4.1 구조
- 큰 맵 1장, 정적 배치 · 메인 존 **10개**는 자유 배치 (레벨 기획 단계에서 결정)
  - Z1~Z9: 파츠 재료 존 · Z10: 마력석 1개 확정 + 회복 위주 존 `(초안)`
- 메인 존 사이는 **커넥터**로 연결
- **스폰 포인트 3곳**, **탈출 구역 4곳** (서로 다른 위치, Exit-D는 2026-10-14 추가 — level-design 1.6) · 스폰은 매 런 3곳 중 1곳 랜덤
- 스폰·탈출 구역 위치는 레벨 기획 단계에서 배치
- **순간이동 지점** 1쌍 (4.2)
- 스테이지 1 배치: [level-design.md](level-design.md)
- 시야: 플레이어 기준 **가로 15u** (카메라 orthographic size 8.4375 · 16:9 → 보이는 범위 30u × 16.9u, 상하 8.4u. 모든 씬 공통)

### 4.2 커넥터
- 적 **스폰 위치는 고정**, 적 구성은 **적 청크 프리셋** 중 하나를 사용
- 커넥터 적은 **순찰** · 구간(홀)당 소청크 1개 (Normal 3 또는 Normal 2 + Straight 1, Standard 스포너) `(초안, 2026-10-10)`. 스폰 둘레 20u · 탈출 통로는 제외
- **커넥터 상자 스폰:** 커넥터마다 상자 스폰 지점이 정해져 있음
  - 런마다 실제로 생성되는 상자 수 = 구간당 **1~2개 랜덤** (공급을 줄이는 구간은 1개 고정, 방 여러 개를 합친 큰 방(R7 회랑)은 2~3개, 레벨 기획)
  - 어느 지점에 생성될지는 매 런 랜덤 → 같은 커넥터라도 상자 위치가 달라짐
  - 위치 변화가 보이도록 구간마다 스폰 지점을 **4곳 이상** 배치 권장
- **갈림길:** 커넥터는 갈림길로 여러 갈래가 될 수 있음
  - 상자 스폰 지점과 적 청크는 **구간(존 A–존 B)** 단위로 소속을 정함 → 커넥터 상자 재료는 그 구간의 두 존 기준 (7.3)
  - 구간별 생성 수로 재료 공급을 조절 (예: 탄약 하향 구간, 레벨 기획)
  - 스폰 포인트·탈출 구역 통로에는 상자 없음
- **순간이동:** 떨어진 두 지점을 잇는 양방향 통로
  - **E 2초 홀드**로 사용 (홀드 중 무방비), 이동 시간 없음
  - 커넥터가 아니므로 상자·적 청크 없음

### 4.3 메인 존
- 메인 존마다 **존 수비대**를 순환 프리셋으로 배치 → 확정 전투 (구성 · 규모는 적 유닛 작업 후 결정 `(미정)`)
  - **생성 방식 (2026-10-10):** **Standard 스포너 사전 배치** (씬 로드 시 생성, 플레이어 감지 시 교전). 첫 배치 후 성능 확인
  - **수비대 프리셋 `(초안, 2026-10-10)`:** 존당 7~8마리, 소탕 30~45초 목표 (level-design 9.3)
    - ① 근접형: Normal 6 + Straight 2 / ② 혼합형: Normal 4 + Tanker 1 + Sniper 1 + Thrower 1 → 일반 존에 번갈아 배치
    - ③ 고위험형 (Z5 · Z8): EliteSniper 1 + Normal 4 + Thrower 1
- **수비대 유형** (6.6)

| 유형 | 적용 존 | 구성 | 클리어 조건 |
|---|---|---|---|
| 일반 몹 존 | 일반 존 (기본) | 일반 몹 청크 (규모 `(미정)`) | 일반 몬스터 전멸 |
| 엘리트 순찰 존 | 일반 존 중 런마다 1~2곳 | 엘리트 1기가 순찰 (일반 몹 없음) | 엘리트 처치 |
| 혼합 존 | 고위험 존 (Z5 · Z8) | 엘리트 1기 + 일반 몹 | 엘리트 포함 전멸 |

- **존 클리어 보상 없음.** 클리어 판정은 체류 추가 웨이브 · 퀘스트 조건으로만 쓰임
- **존 상자:** 존마다 **3개**, 후보 지점 **5~6곳** 중 랜덤 생성, **잠금 없음** (초반 탐사 인증 상자 포함, 9.3) (7.3)
  - 수비대는 상자만 털고 도망가는 플레이를 막는 최소한의 전투 장치 → 전투 없이 상자 1개를 열려면 **2~3회 피격 위험**을 감수하도록 배치
  - 존을 모두 정리하지 않아도 상자 일부만 털고 떠날 수 있음 → "얼마나 싸우고 얼마나 가져갈지"가 플레이어 판단
- **체류 추가 웨이브:** 존 클리어 후 **45~60초**가 지나면 추가 웨이브 1회
  - **방문마다 1회.** 존을 벗어나면 체류 시간 초기화
  - 진행 중 주기 습격 타이머 초기화 · 정지 (4.6)
- **퀘스트 디펜스:** 구역 정화 퀘스트(9.3)를 수주했을 때만 존 안의 오브젝트와 상호작용 → 디펜스 웨이브. **엘리트 없음** (2026-10-12, 웨이브 구성은 [quest-db.md](quest-db.md) 1.5). 진행 중 주기 습격 타이머 초기화 · 정지
  - 규칙상 제한은 없지만, 존에 기존 엘리트가 있으면 오브젝트 상호작용(홀드)과 디펜스를 안정적으로 하려면 실제로는 먼저 처치해야 함
- **출입구 잠금 없음:** 평소에는 언제든 이탈 가능
  - **예외 — 퀘스트 디펜스 중 출입구 봉쇄 (2026-10-12):** 작동(E 2초 홀드)하는 순간 존의 출입구가 모두 닫히고, 웨이브를 모두 처치해야 열림 → 시작하면 클리어하거나 사망할 때까지 나갈 수 없음. 닫힐 때 문간에 있던 적은 방 안쪽으로 밀어 넣음
- **이중 전투 허용:** 수비대를 정리하기 전의 존에서도 주기 습격이 겹칠 수 있음 (의도된 위험)
- **보스 해금 기믹 (알파-2):** 기믹 3개. 기믹룸은 메인 존이 아닌 **일반 방에서 접근**
  - 퀘스트는 기믹으로 **유도**만 함 (예: "Z5의 엘리트 처치" → 드랍된 인장을 특정 기믹 구역에서 사용 → 기믹룸 접근). 열쇠의 쓰임새는 플레이어가 유추
  - 기믹 열쇠(인장 등)는 관련 퀘스트를 수주했을 때만 드랍 (7.2)
  - 한 번 켜면 **스테이지에 영구 적용** (가동 즉시 저장되며, 이후 런에서 사망하더라도 해금 상태가 유지됨)
  - 3개를 모두 켜는 순간 **보스룸이 영구 개방**되며, 해당 런의 탈출/사망 여부와 무관하게 항시 저장됨
  - 보스룸은 기믹 3개를 켜기 전까지 **항상 막혀 있음** (우회 진입 없음)
  - **게임 엔딩:** 보스 처치 퀘스트를 **수주한 상태에서** 보스를 처치하면 게임 엔딩. 보스 퀘스트 · 엔딩 연출은 추후 기획 `(미정)`
  - 기믹 구역 · 기믹룸 위치와 기믹 열쇠 퀘스트는 추후 기획. **당분간 현재 위치(Z1 · Z5 · Z7 곁방) 유지** `(미정)`

### 4.4 탈출
- **탈출 구역 크기:** **4u × 4u** (정사각형 구역)
- 런 시작 **3분 후** 탈출 구역 활성화 (그 전에는 비활성 표시)
- 탈출 구역 안에서 **10초** 대기하면 탈출 성공
- **피격 상호작용:** 상호작용 채널링이 아닌 '구역 내 체류/생존 대기' 판정이므로, **적에게 피격을 당해도 구역(4u×4u) 안에 머물고 있으면 타이머가 취소되지 않고 계속 진행됨**
- 구역을 벗어나면 **타이머 초기화**
- 탈출 대기 전용 습격은 없음. 주기 습격(4.6)이 대기 중에 겹칠 수 있음

### 4.5 존별 재료

**설계 규칙**
- 존마다 **주 재료 1 + 부 재료 2**
- 어느 존도 한 파츠의 A·B·C 재료 3종을 모두 주지 않음 → 파츠 하나를 강화하려면 최소 2개 존을 돌아야 함
- D 재료까지 포함하면 Z1(약실&노리쇠)과 Z3(총열)이 4종 중 3종을 주지만, 4종 전부를 주는 존은 없음

### 4.6 주기 습격
- **타이머:** 던전 입장 시 가동. 간격 **2분 20초 ~ 3분 랜덤**, 남은 시간은 플레이어에게 **공개하지 않음**
- 습격이 시작되면 타이머를 초기화하고 **계속 진행** (습격 전투 중에도 흐름)
- **웨이브 이벤트 중 정지:** 퀘스트 디펜스 · 체류 추가 웨이브(4.3) · 메인 스토리 이벤트 웨이브(Q2 매복 등)에 참여하는 동안 타이머를 초기화하고 정지 → 세 겹 전투 방지
- **경고:** 습격 5~10초 전 뿔피리 소리 등으로 예고 → 좁은 통로에서 막을지, 넓은 곳(작은 방 · 메인 존)으로 갈지 선택을 강제
- **생성 위치 (2026-10-10, 구현 기준으로 확정):** 플레이어 중심 **22u 정사각형 바깥 · 45u 정사각형 안** (약 11~31u)의 바닥 타일 위, 청크마다 습격 포탈 1개. 포탈이 솟아오르는 연출로 화면 안 팝인(Pop-in)을 가림 (`EnemyRaidSpawner`)
  - 이전 기준(17u · 레벨 기획 10~14u)은 폐기
  - **본대 한쪽 · 반대쪽 소수 배치는 평가 빌드(12.1) 이후 후속 작업** `(미정)`
- **구성:** 일반 몹 청크, 엘리트 없음. **초반은 완만하게** `(초안, 2026-10-10)`: 1회차 Normal 6~8 · 2회차 Normal 8 + Straight 2 · 3회차부터 Tanker · Sniper · Thrower 섞음. 습격당 교전 30~40초(level-design 9.3) 기준으로 플레이테스트 조정
- **추적 및 비디스폰 규칙:** 습격 몬스터들은 플레이어를 무조건 끝까지 추적하며, 따돌릴 수 없음 (디스폰 없음). 전투를 회피하고 도망치면 다음 회차 습격 몬스터와 누적 중첩되어 감당하기 어려운 대규모 적 군세(트레인)를 형성하도록 의도됨.
- **시점 (웨이브 이벤트가 없을 때):** 1회차 2:20~3:00 · 2회차 4:40~6:00 · 3회차 7:00~9:00 · 4회차 9:20~12:00 → 12분 런에서 대개 **4회**
  - **회차 구성 데이터를 다 쓴 뒤**(12분 초과 등)에는 **마지막 회차 구성을 반복** → 초과 페널티와 함께 압박 유지
  - 3회차는 탈출 무렵의 압박, 4회차는 제한 시간 직전의 막바지 압박 역할

### 4.7 환경 지형 (물 · 수로) `(초안)`
- **역할:** 캐릭터(플레이어 및 지상 적) 물리적 이동 차단, **시야 및 탄환/투사체는 100% 통과** (벽은 둘 다 막음)
- **충돌 및 판정:** `Water` 레이어 콜라이더 적용. 샷건 펠릿 및 적 투사체 충돌 마스크에서 제외
- **대쉬 상호작용:** **대쉬로 물/웅덩이를 건너뛸 수 없음** (벽과 동일하게 충돌하여 대쉬 중단)
- **적 AI 길찾기 및 예외:**
  - 지상 보행 적(Normal, Tanker 등)은 NavMesh 상 `Not Walkable`로 우회 이동.
  - **돌진형 적(Straight):** 공중에 떠 있는 비행/부유(Flying) 판정으로 제작되어 **물/수로와 충돌하지 않고 물 위를 건너 플레이어에게 직진 돌진**함 (벽에만 충돌).

### 5.3 데미지 공식

```
최종 데미지 = 펠릿 데미지 × 거리 배율 × 크리티컬 배율 × 관통 배율
```
- 모든 배율은 **곱연산**
  - 예: 근접 120% × 크리티컬 150% = 180%
  - 예: 관통한 두 번째 적 = 크리티컬 150% × 관통 70% = 105%

**거리 배율**

| 거리 d | 배율 |
|---|---|
| 0 ≤ d < 3u | **120%** |
| 3u ≤ d ≤ 4u | **100%** (기준 거리) |
| 4u < d ≤ 6u | **80%** |
| 6u < d < 10u | 곡선: `0.1 + 0.7 × (1 − t²)`, `t = (d − 6) / 4` |
| d ≥ 10u | **10%** |

- 곡선 값: 7u 76% · 8u 63% · 9u 41%
- 시야(가로 15u) 안에는 10% 구간(10u 이상)의 적도 보임. 최대 사거리(12u)를 넘는 적은 맞힐 수 없으므로 처치하려면 접근해야 함
- 총열 강화: 모든 구간 경계를 레벨당 +10% (Lv5 = ×1.4 → 120% 구간 4.2u, 기준 5.6u, 80% 8.4u, 10% 14u)

**크리티컬**
- 배율 **150%**, 기본 확률 **0%**
- 판정은 **발 단위**: 크리티컬이 나면 그 발의 모든 펠릿에 적용
- **확정 크리티컬 탄 (탄약 Lv3)**: 재장전으로 탄을 **4발 장전할 때마다** 4번째로 넣은 탄은 크리티컬이 확정됨 (용량 8발이면 한 탄창에 최대 2발). 장전 횟수는 부분 재장전에 걸쳐 이어지고, 쏠 때 그 탄에서 터짐 · HUD 탄환 아이콘에 표시

**관통 (탄띠 Lv2)**
- 모든 펠릿이 **적(몬스터)에 한해 1명까지 관통** (두 번째 적에게 70% 피해). 상자·오브젝트·투사체 등은 관통 불가
- **Tanker·벽은 관통 불가**

public enum EnemyType

- **추적(Aggro) 규칙 (2026-10-10, 구현 기준으로 확정):** 생성 방식에 따라 다름
  - **존 수비대 · 커넥터 순찰** (Standard 스포너): 정찰 범위(스포너 기준 **15u**)를 벗어나면 추적을 풀고 제자리로 귀환. 엘리트도 같음
  - **주기 습격 · 웨이브** (Raid · Destruction 스포너): 해제 없이 끝까지 추적 → 회피하면 다음 회차와 겹쳐 트레인(Train)이 되는 위험은 습격이 담당
- Sniper·Thrower는 **주요 공격 몹**이고 플레이어가 빠르게 접근할 수 있으므로 체력을 500으로 높게 잡음 (접근 후에도 바로 녹지 않도록)
- 조합 예: Tanker가 앞을 막고 뒤에서 Sniper·Thrower가 공격 → 샷건 근접전과 우회를 유도

### 6.3 Sniper 사격 패턴
1. **차지 (1.5초):** 플레이어를 추적하는 광선 표시
2. **깜빡임 (0.5초):** 조준 고정 직전 광선이 깜빡임
3. **위치 확정 → 0.3초 후 발사:** 확정 후 텀 동안 회피 가능

- **위치 파악:** 별도 표시 없이 예고 광선의 방향으로 추적 (광선은 Sniper에서 플레이어까지 전체 길이로 표시)
- 공격 후 바로 다음 차지를 시작하므로, 접근하는 동안에도 광선이 위치를 알려줌
- 플레이어의 공격은 거리 보정을 받으므로 처치하려면 접근해야 함
- 청크 · 웨이브 구성 시 Sniper는 동시에 2마리 이하 권장 (광선 구분)

### 6.4 Thrower 폭탄
- 폭발 반경 **3u**, 데미지 1
- 착탄 지점에 **경고 존** 표시 (반경 3u 원)
- 폭탄끼리 최소 간격: 착탄 지점 중심 사이 **4u 이상**
  - 원끼리 일부 겹치지만 한 덩어리가 되지 않아 바깥쪽으로 빠져나갈 방향이 남음
  - 폭탄 사이에 안전지대가 필요하면 6u 초과로 조정
- 폭탄 2~3개 중 1개만 플레이어 위치를 노리고, 나머지는 주변에 흩뿌림
- 투척 → 폭발: **1.0초**
  - 이동속도 6.5u/초 환경에서 즉시 반응하지 않으면 걷기만으로 탈출이 빠듯하여 즉각적인 대쉬 또는 방향 전환 강제

### 6.5 EliteSniper
- 기본 공격은 Sniper와 같되 **차지 시간 0.7배** (1.5초 → 1.05초)
- 사격 차지 전 **플레이어가 5u 이내**인지 확인 → 가까우면 사격 대신 기믹 하나를 랜덤 실행
  - **수류탄 3개 투척:** 플레이어 근처, Thrower 폭탄 규칙 적용
  - **텔레포트:** 플레이어로부터 7u 이상 떨어진 같은 존 안의 랜덤 위치로 이동 후 사격 패턴 재개
- 기믹 쿨타임 **6초** (연속 발동 방지)
- 등장 위치: **고위험 존 Z5·Z8의 혼합 수비대** (4.3)

### 6.6 엘리트
- **종류:** 기존 적 타입을 강화하는 방식 (예: EliteSniper = Sniper 강화형). 목록은 적 유닛 작업 후 결정 `(미정)`
- **배치:** 존마다 **최대 1마리**
  - 일반 존: 런마다 **1~2마리**를 엘리트 순찰 존 1~2곳에 1마리씩 (4.3)
  - 고위험 존(Z5 · Z8): 혼합 수비대에 1마리
  - 퀘스트 디펜스: 없음 (2026-10-12)
  - 주기 습격: 없음
  - 엘리트 처치 관련 퀘스트를 수주하면 개체 수가 달라질 수 있음
- **추적:** 6.2 추적 규칙을 따름 (수비대 엘리트는 정찰 범위 15u 밖에서 귀환)
- **드랍:** 전리품 주머니 (7.2)
- **XP:** 20 (9.2)

### 7.2 상자
- 보상은 **상자**(커넥터 상자, 메인 존의 존 상자)와 **엘리트 드랍**으로 획득. 일반 몬스터는 드랍 없음
- **엘리트 드랍:** 전리품 주머니 1개, 런 끝까지 유지. 열 때는 상자와 같은 화면 (홀드 없이 열람)
  - 마력석을 제외한 재료 9종 중 **균등 랜덤 1~2개** (같은 재료가 겹칠 수 있음)
  - 퀘스트 전용 품목(인증 아이템 · 회수 아이템 · 기믹 열쇠 등)은 **관련 퀘스트를 수주했을 때만** 드랍
- 상자에서는 **재료**만 나옴
- 상자는 **매 런 초기화**
- 상자 위치와 내용물은 **런 시작 시 한 번에** 결정 (열 때 정하지 않음). 엘리트 전리품 주머니만 처치 시점에 생성
  - **존 상자:** 존마다 **세트**(상자 3개분 내용) 2~3개 중 하나를 랜덤으로 고르고, 생성된 3곳에 섞어서 배정 (7.3)
  - **커넥터 상자:** 프리셋 없이 규칙으로 생성 (7.3)
- **생성 순서:** 존 상자 → 커넥터 상자 → 퀘스트 아이템 (9.3). 퀘스트 아이템은 이미 생성된 상자에 넣고, 상자를 새로 만들지 않음 (회수 고정 상자 제외)
- 개방: **E 2초 홀드** (개방 중 무방비). 피격 자체로 즉시 취소되지는 않으나, **넉백 등으로 상호작용 유효 반경(1.5u)을 벗어나면 게이지가 즉시 초기화(0%)**됨. 이미 연 상자는 홀드 없이 바로 열람 · 상호작용
- **루팅 UI 조작 및 실시간 진행:** 상자/인벤토리 UI가 열려 있는 동안에도 **게임은 일시정지되지 않고 실시간으로 흐름**. 루팅 중 이동(WASD), 대쉬(우클릭), 사격(좌클릭), 또는 ESC 입력 시 **루팅 창이 즉시 닫히며 해당 행동이 실행됨**
- 커넥터 상자는 정해진 스폰 지점 중 일부에만 생성 (4.2)
- 상자 배치·세부 프리셋은 레벨 기획 단계에서 작성

  - 두 존에 같은 재료가 있으면 슬롯 수만큼 자주 나옴 (예: Z1–Z9 구간의 납덩이 = 6슬롯 중 2)

- 그 뒤 **30% 확률로 치유 약초 1개 추가**
- 마력석은 메인 존의 존 상자(Z5 · Z8 · Z10)에서만 나옴 (엘리트 드랍 · 퀘스트 보상 제외)
- 갈림길이 있는 커넥터는 상자 스폰 지점이 속한 구간의 두 존 기준 (4.2)

### 7.4 가방 (런 중 소지품)
- 기본 **5칸**, 칸당 같은 재료 **5개**까지 스택 → **칸 수 = 들고 다닐 수 있는 재료 종류 수**
- 플레이어 레벨로 최대 **8칸** (Lv3·6·9에 +1칸)
- 가방이 가득 차면:
  - **새 아이템 클릭 시 반응 없음:** 가방이 가득 찬 상태에서 상자 안의 새로운 재료를 클릭하면 **아무 일도 일어나지 않음** (상자 안에 그대로 유지됨).
  - **바닥에 버리기** → 즉시 소멸
  - **상자로 옮기기** → 그 상자에 보관, 이번 런 동안 다시 꺼낼 수 있음 (런 종료 시 초기화)
  - **교체:** 상자 화면에서 가방 재료를 먼저 상자/바닥으로 비운 후 획득
- **설계 의도:** 치유 약초가 모든 존에서 나와 가방 칸을 차지 → 회복 재료와 강화 재료 사이의 선택

| 플레이어 Lv | 가방 | 강화 재료 종류 (치유 약초 1칸 제외) | 도달 시점 |
|:-:|:-:|:-:|:-:|
| 1 | 5칸 | 4종 | 시작 |
| 3 | 6칸 | 5종 | 약 3.5런 |
| 6 | 7칸 | 6종 | 약 11런 |
| 9 | 8칸 | 7종 | 약 21런 |

- 후반 가방 여유는 파츠 Lv3→4부터 추가되는 D 재료(8.3)로 상쇄

### 7.5 창고
- 재료 **종류별 1칸** → 10칸, 칸당 수량 제한 없음
- **쉘터 복귀 시 자동 누계:** 탈출에 성공해 쉘터로 돌아오면, 런 중 획득한 재료(가방 안의 재료)가 창고의 같은 종류 칸에 **자동으로 합산**됨
  - 플레이어가 옮기는 조작 없음 (정산 화면에서 획득 내역만 표시)
  - 예: 창고 철괴 12개 + 가방 철괴 7개 → 창고 철괴 19개
  - 가방은 합산 후 비워짐
- 사망 시 가방 재료만 소실 (창고 재료·강화 레벨은 유지)

- **시전(Casting) 공통 규칙:**
  - 머리 위 재장전 막대(`ActionProgressBar`)를 공유해 사용 진행도 표시.
  - 아이템 사용 중 **산탄 인디케이터(`SpreadArcIndicator`) 숨김**, 마우스 커서 조준 회전은 허용.
  - 재장전 도중 소모품 키 입력 시 **재장전 즉시 취소 후 소모품 시전으로 전환**.
  - 아머는 이동 가능하나 **사격/재장전/대시/피격 시 취소**, 회복은 이동 시에도 취소.
  - 취소 시 막대가 **붉은색으로 변하며 좌우로 바들바들 흔들린(Shake) 후 소멸** (아이템 미소모 보존).

  - 상세 규칙: [`Docs/consumable-system-spec.md`](consumable-system-spec.md) 참고
- **투척물(수류탄류) 조작 규칙:**
  - 6시 퀵슬롯 단축키 입력 시 샷건 인디케이터 숨김 및 곡선 투척 인디케이터(사거리 1~8u 조절 가능, 폭발 반경 표기) 출력 (단축키 재입력 시 조준 취소 토글).
  - 직사 투척 판정(벽/장애물 충돌 시 낙하), 마우스 좌클릭 시 아이템 1개 소모 후 투척. 지연 폭발 시 **플레이어 자해 피해(Friendly Fire)** 동일 적용. 섬광탄 피격 시 화면 백색 플래시 적용.
- 파편 수류탄 250 = Lv1 샷건 1발 전탄 명중과 같은 값 (Normal은 못 잡고, 샷건 1발로 마무리)

### 7.7 간이 제작대 `(도입 검토 중 · 미정)`

- **쉘터에서만** 가능 (런 중에는 스펙 고정), 파츠 **Lv1 시작 · 최대 Lv5**

### 8.3 강화 비용

- 파츠마다 **A·B·C 재료 3종**, 레벨이 오를수록 수량 증가

- **Lv3→4, Lv4→5**에 **마력석** 추가

| Lv4 → 5 | 14 | 11 | 8 | 4 | 3 |

- v1.6에서 약 +20% (파츠당 71 → 85개). 구역 정화 보상(9.3)이 가방을 거치지 않고 창고로 들어와 성장 기간을 직접 줄이므로 보정. 증가분은 뒤 단계에 몰아 초반 강화 체감은 유지

### 8.4 성장 기간 검증
- 파츠 하나 Lv5: 일반 재료 **85개** + 마력석 4개
- 전 파츠 Lv5: 일반 재료 **425개** + 마력석 20개
  - 런당 실제 반입 약 19개 (가방 5~8칸, 치유 약초 1칸, 사망 약 20% 감안)
  - **성장 속도는 던전 안 공급량이 아니라 가방 반입량이 결정** → 존 상자 분산 · 엘리트 드랍은 성장 기간에 영향이 작음
  - **퀘스트 재료 보상**(9.3)은 탈출 후 창고로 바로 들어와 가방 병목을 거치지 않음 → 성장 기간을 직접 줄임
  - 아래 표는 구역 정화 보상만 반영. 다른 퀘스트는 퀘스트당 강화 재료 1개(총합 약 40개 이하)라 최대 약 2런 단축 → 퀘스트 풀이 정해지면 추가 반영

    | 클리어한 구역 정화 | 받은 보상 | 성장 기간 |
    |---|:-:|:-:|
    | 0개 | 0개 | 약 22.4런 |
    | 약 10개 | 약 40개 | 약 20.3런 |
    | 20개 전부 | 약 80개 | 약 18.2런 |

    - 계산: (425 − 받은 보상) ÷ 19. 구역 정화를 하지 않으면 목표(약 21~22런)와 같고, 할수록 빨라짐
  - 마력석 20개: 마력석은 존 상자(Z5 · Z8 · Z10)에서만 나옴 (커넥터 상자 · 엘리트 드랍 · 퀘스트 보상 제외)

    | 마력석 공급원 | 방문당 마력석 (존 상자 합계) | 20개에 필요한 방문 |
    |---|:-:|:-:|
    | Z5 (고위험) | 약 2.5 | 약 8회 |
    | Z8 (고위험) | 약 0.5 | 약 40회 |
    | Z10 (일반) | 1 (확정) | 20회 |

    - Z10: 북쪽 동선(Z1 · Z9 총열 재료)을 도는 런에서도 마력석을 1개씩 모을 수 있음
      - 예: 약 6런에서 Z10 → 마력석 6개 → 남은 14개 = Z5 약 6회 → 남동쪽 동선(Z4 · Z6 탄띠 재료) 런 안에서 해결
    - Z10 유황 가루는 소량이라 일반 재료 기준 런 수에는 거의 영향 없음

## 9. 플레이어 레벨 · XP · 퀘스트

### 9.1 플레이어 레벨
- **Lv1 시작 · 최대 Lv10**, 비용은 XP
- 레벨업마다 **이동속도 → 가방 +1칸 → 체력 +1칸** 순서, 3번 반복

| 레벨업 | 효과 | 필요 XP | 누적 XP | 누적 런 (750 XP/런) |
|:-:|---|:-:|:-:|:-:|
| Lv1 → 2 | 이동속도 +5% | 1,200 | 1,200 | 1.6 |
| Lv2 → 3 | 가방 +1칸 (6칸) | 1,400 | 2,600 | 3.5 |
| Lv3 → 4 | 체력 +1칸 (6칸) · 대쉬 충전 시간 −0.5초 (1.5초) | 1,650 | 4,250 | 5.7 |
| Lv4 → 5 | 이동속도 +5% | 1,850 | 6,100 | 8.1 |
| Lv5 → 6 | 가방 +1칸 (7칸) | 2,100 | 8,200 | 10.9 |
| Lv6 → 7 | 체력 +1칸 (7칸) · 대쉬 충전 시간 −0.5초 (1.0초) | 2,300 | 10,500 | 14.0 |
| Lv7 → 8 | 이동속도 +5% | 2,550 | 13,050 | 17.4 |
| Lv8 → 9 | 가방 +1칸 (8칸) | 2,750 | 15,800 | 21.1 |
| Lv9 → 10 | 체력 +1칸 (8칸) | 2,950 | 18,750 | 25.0 |

- 런당 평균 750 XP = 런 XP 500 + 퀘스트 XP 평균 250 (v1.5 기준: 체인 12개를 25런에 걸쳐 완료)
- 퀘스트를 하지 않으면 약 37런 → 퀘스트가 성장 속도의 핵심
- **평가 빌드 (12.1):** 3런 안에 Lv3(가방 +1칸)까지 체감하도록 **Lv1→2 · Lv2→3 필요 XP를 낮춤** `(초안, 2026-10-10)`: **Lv1→2 400 · Lv2→3 700** (누적 1,100). 메인 Q1 런 탈출(약 450~600 XP)로 Lv2, Q2 런까지 누적 약 1,100~1,400 XP로 Lv3. Lv3→4 이후는 위 표 값 유지
- ⚠️ **v1.6 재설정 예정 `(미정)`:** 주기 습격(런당 약 4회) · 체류 추가 웨이브 · 구역 정화로 처치 수가 늘고, 존 클리어 XP가 없어지고, 퀘스트 구조(9.3)가 바뀜 → 적 청크 구성이 정해진 뒤(적 유닛 작업 후) 필요 XP와 퀘스트 XP를 다시 계산

### 9.2 XP 획득 (초안)

| 경로 | XP |
|---|---|
| 일반 적 처치 | 5 |
| 엘리트 적 처치 | 20 |
| 탈출 성공 보너스 | 런 획득 XP의 +50% |
| 사망 | 런 획득 XP의 30%만 유지 |
| 퀘스트 달성 | 300 / 500 / 800 (9.3) |

- 메인 존 클리어 XP(v1.5: 100)는 v1.6에서 삭제 (존 클리어 보상 없음, 4.3)
- 예시 계산은 레벨 경험치 한도 재설정(9.1) 때 다시 작성
- ⚠️ 초반 처치 속도가 느려 실제 런 XP가 500보다 낮을 수 있음 → 플레이테스트로 검증

### 9.3 쉘터 퀘스트
- 쉘터 퀘스트 게시판에서 수주, 조건 달성 후 **탈출해야 클리어**
- 사망 시 이번 런 진행은 인정 안 됨 (퀘스트는 유지)
- **반복 퀘스트 없음:** 모든 퀘스트는 1회성

**슬롯**

| 슬롯 | 수 | 진행 방식 | 퀘스트 타입 |
|---|:-:|---|---|
| 스토리 | 1 | 선형, 항상 진행 | 메인 스토리 |
| 의뢰 | 최대 3 | 동시 진행 | 초반 탐사 · 구역 정화 · 보물찾기 · 회수 |

- 의뢰는 쉘터에서 자유롭게 포기 가능. 게시판은 쉘터에 돌아올 때만 갱신
- 한 런에 도는 존은 2~3곳이라 의뢰 3개를 한 런에 모두 끝내기는 어려움 → 여러 런에 걸쳐 나눠 진행

**퀘스트 타입**

| 타입 | 목표 | 규칙 |
|---|---|---|
| 초반 탐사 | 존 클리어 **인증 아이템** 회수 | 초반 한정. 수주 후 입장하면 해당 존의 상자 1개에 인증 아이템 **확정 1개** (예: "대장간 탐사" → Z1). 그 상자(존 상자 3개 중 1개)는 **잠금 없음** → 존 클리어 여부와 상관없이 열 수 있지만, 수비대 사이에서 큰 피해를 감수해야 해서 사실상 소탕이 필요함 (규칙이 아니라 수비대 배치로 만드는 의도). 대상: 메인 존 **10곳**. 고위험 존(Z5 · Z8)의 초반 탐사는 **다른 8곳 중 4개를 완료**해야 수주 가능 |
| 구역 정화 | 퀘스트 디펜스 (4.3) | 수주하면 존 안의 오브젝트와 상호작용 가능 → 디펜스 웨이브를 모두 클리어하면 정화. 엘리트 없음. **존마다 2단계** (약 20개). 필수가 아닌 풀에 남는 퀘스트 |
| 보물찾기 | 숨겨진 보물 회수 | **입장 시 위치 결정.** 퀘스트는 **인접한 존 2곳**을 명시하고, 보물은 두 존의 존 상자 + 두 존 사이 커넥터 상자 중 **이번 런에 생성된 상자**에서 랜덤. 지도에 범위 표시 없음. 상자를 새로 만들지 않으므로 공급량 변화 없음 |
| 회수 | 지정 아이템 회수 | 수주 후 **지정된 엘리트를 처치**하거나 **존의 고정된 상자**(랜덤 위치인 존 상자와 별개)에서 획득. 고정 상자는 잠금 없이 항상 2초 홀드로 열 수 있지만, 수비대와 싸워야 안정적으로 열 수 있음. 고정 상자는 퀘스트를 수주한 런에만 생성되며 **회수 아이템 1 + 치유 약초 1~2개**가 들어 있음 |
| 메인 스토리 | 보스 기믹으로 유도 | 기믹을 직접 해금하지 않고 첫 행동만 알려 줌 (4.3). 기믹 열쇠 관련 퀘스트는 추후 기획 |

- **퀘스트 아이템**(인증 아이템 · 보물 · 회수 아이템 · 기믹 열쇠)은 관련 퀘스트를 수주했을 때만 등장하고, **가방 칸을 차지**하며, **들고 탈출**해야 인정
  - 초반 가방이 빠듯하지만 초반 탐사는 초반에만 진행되고 레벨업으로 가방이 늘어나(9.1) 금방 해소됨

**구역 정화 해금 (존별)**

| 단계 | 해금 조건 | 보상 (창고로 바로 지급) |
|:-:|---|---|
| 1단계 | 그 존의 초반 탐사 퀘스트를 **완료**한 뒤 그 존을 1회 이상 방문하고 **탈출 성공** (Z5 · Z8 포함 모든 존 동일) | 해당 존의 주 재료 1 + 부 재료 2 |
| 2단계 | 그 존의 1단계를 클리어한 뒤 그 존을 1회 이상 방문하고 **탈출 성공** | 해당 존의 주 재료 2 + 부 재료 3 |

- 보상은 탈출 후 쉘터에서 판정 → **창고로 바로 지급** (가방을 거치지 않음, 성장 기간 영향은 8.4)
- 마력석은 보상에서 제외 → Z5(주 재료 마력석) · Z8 · Z10(부 재료 마력석)은 그 존의 다른 재료로 채움
- Z10은 **치유 약초도 보상에 포함** (주 재료가 치유 약초)

**보상 · XP**
- **구역 정화 외 퀘스트:** XP + 재료 (창고로 바로 지급)
  - 재료: 퀘스트 관련 존의 **부 재료 1개 + 치유 약초 3개**
  - 구역 정화를 뺀 퀘스트의 강화 재료 보상 총합은 **약 40개 이하** (약 2런 분량). 넘으면 강화 비용(8.3)을 다시 조정
  - 관련 존이 둘인 퀘스트(보물찾기)는 둘 중 하나, 관련 존이 없는 퀘스트(메인 스토리 일부)의 부 재료는 퀘스트 풀 기획 때 결정
- 퀘스트 XP 수치는 레벨 경험치 한도 재설정(9.1)과 함께 결정 `(미정)`
- 퀘스트 풀(전체 수 · 해금 순서)과 스토리 체인은 추후 기획. v1.5의 고정 체인 12개는 폐기

### 12.1 평가 빌드 (마감 2026-10-14)

- **평가 방식:** 빌드본을 평가자가 직접 플레이 → 플레이 가능한 상태가 필수
- **기준 플레이 분량:** **3런**. 퀘스트 라인이 평가에서 눈에 띄는 부분
- **보스:** 현재 성장 · 해금 흐름(20런 이상)으로는 평가 3런 안에 보스까지 도달할 수 없음. 보스룸은 4.3 규칙(기믹 3개 작동 시 개방, 퀘스트 수주 후 처치 = 엔딩) 그대로 유지
- **튜토리얼 포함:** 기본 조작 튜토리얼 + 첫 번째 런 컷씬 안내 (11장). 흐름: 타이틀 → 새 게임 → 튜토리얼(**강제 1회, 스킵 불가**, 완료 플래그 저장) → 쉘터
- **메인 Q2 매복 웨이브 `(초안)`:** H2 홀, 엘레나 상호작용으로 Destruction 스포너 시작. 2웨이브: ① Normal 5 + Straight 2 ② Normal 3 + Tanker 1 + Thrower 1 (약 60초). 진행 중 주기 습격 타이머 정지 (4.6)
- **보스 제외:** 평가자가 닿을 수 없으므로 보스 · 기믹은 만들지 않음. 보스룸 문은 막힌 상태로 둠
- **초반 탐사 의뢰 (2026-10-12):** Z3 · Z4 · Z5 · Z6 · Z7 · Z8 · Z9 · Z10 8곳. Z1 탐사는 메인 Q1, Z2 탐사는 메인 Q2가 대신함. Q2 완료 시 8곳 모두 수주 가능 (고위험 Z5 · Z8도 9.3의 4곳 완료 잠금 없음)
- **퀘스트 범위 (2026-10-12):** 총 13개 = 탐사 10(강제 Q1 · Q2 + 수주형 8) + 구역 정화(퀘스트 디펜스) Z4 · Z7 1단계씩 + Z5 엘리트 스나이퍼 처치 1. 디펜스는 그 존의 탐사 완료만으로 해금. 3런 흐름 = Q1 → Q2 → 랜덤 스폰 해금 후 자유 런. 목록: [quest-db.md](quest-db.md)
- **적 배치 범위:** 메인 존 10곳 수비대 + 모든 커넥터 구간 순찰. 청크 프리셋을 여러 곳에 재사용. **E1 주변(Z1 · Z2 · Z9 · H2 · 북서 홀)부터** 완성 (메인 Q1 · Q2가 E1 고정 스폰)
- **제외 기능:** 엘리트 순찰 존 랜덤 선정(엘리트는 Z5 · Z8 혼합 수비대에만), 체류 추가 웨이브
