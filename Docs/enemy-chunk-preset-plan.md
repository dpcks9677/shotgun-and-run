# Enemy Chunk 프리셋 및 전투 경험 기획안

작성일: 2026-10-14. 수정일: 2026-10-15.

## 1. 목표와 설계 원칙

플레이어가 각 타입의 Enemy에 대한 전투 경험을 습득하고, 다양한 구성에 대처할 수 있는 능력을 기르는 것을 목표로 합니다.

- **단일 Enemy:** 한 개체의 Attack·Move·Skill을 관찰하고 대응 방법을 익힙니다.
- **단일 타입 여러 마리:** 같은 행동이 여러 개체에서 겹치는 상황을 경험하며, 거리 유지·회피 방향·공격 기회를 판단합니다.
- **복합 타입 여러 마리:** 서로 다른 공격과 이동, 스킬이 함께 발생하는 상황에서 이동 경로와 처치 우선순위를 선택합니다.

Chunk 세팅은 아래 기존 프리셋 활용안을 기본으로 합니다. 각 구성은 플레이어에게 서로 다른 전투 상황을 제공하며, 단순한 적 수량 증가뿐 아니라 대응 방식의 다양성을 만드는 데 목적을 둡니다.

## 2. 현재 프로젝트와 Enemy별 전투 경험

현재 Chunk는 Enemy의 **타입과 개수**로 구성됩니다. Standard 스포너는 프리셋을 직접 참조하며, Raid·Destruction은 EnemyChunk 데이터를 사용합니다. 아래 Enemy 설명은 현재 코드 기준입니다.

| Enemy | 간단한 설명 | Attack: 기본 공격과 전투 경험 | Move: 이동과 전투 경험 | Skill: 특수 행동과 전투 경험 |
|---|---|---|---|---|
| Normal | 근접 추적형 Enemy | 근접 범위 공격 → 공격 거리 밖을 유지하고 접근한 적을 처리 | 플레이어 추적 → 여러 개체를 모으거나 포위되기 전에 이동 | 주기적인 일시 가속 → 추적 속도 변화에 맞춰 거리와 공격 시점 조절 |
| Straight | 직선 돌진형 Enemy | 돌진 중 충돌 공격 → 돌진 방향을 피하고 공격 후 빈틈 활용 | 플레이어를 추적하다 돌진 시 직선 이동 → 측면 회피와 경로 예측 | 돌진 예고, 벽 충돌 시 경직 → 예고를 읽고 벽으로 유도한 뒤 반격 |
| Sniper | 원거리 저격형 Enemy | 조준선 예고 후 사격 → 사선을 읽고 엄폐·측면 이동으로 대응 | 시야가 막히면 표적을 향해 이동하고, 시야 확보 시 사격 → 엄폐를 이용해 접근 경로 선택 | 별도 추가 스킬 없음. 조준선과 깜빡임으로 공격 시점 판단 |
| Thrower | 폭탄으로 지역을 견제하는 Enemy | 폭탄 여러 개 투척 → 경고 범위에서 벗어나며 공격 기회 확보 | 가까우면 후퇴하고, 멀면 접근하며, 적정 거리에서 좌우 이동 → 이동하는 표적과 거리를 좁히기 | 폭탄 분산 배치로 이동 지역 제한 → 여러 경고 범위를 비교하여 안전한 경로 선택 |
| Tanker | 높은 체력과 방어를 가진 근접형 Enemy | 근접 범위 공격 → 긴 교전 중에도 공격 거리 관리 | 느린 추적 → 이동 공간을 확보하며 공격 대상 선택 | 피해 감소 방어와 예고 후 돌진 → 방어 중 공격 효율을 판단하고 돌진을 피해 반격 |
| EliteSniper | 저격에 폭탄·텔레포트가 결합된 Enemy | 일반 Sniper보다 짧은 조준 시간의 사격 → 빠르게 사선을 확인하고 대응 | 일반 추적 이동 없이 텔레포트로 위치 변경 → 이동한 위치를 다시 확인하고 접근 경로 재설정 | 사격 준비 전 폭탄 투척, 근접 시 텔레포트 → 폭탄 회피와 표적 위치 변화에 함께 대응 |

Attack은 기본 피해 행동, Move는 이동 방식, Skill은 전투에 변화를 주는 특수 행동으로 구분합니다. 돌진과 폭탄처럼 여러 관점에 걸친 행동은 각각의 대응 경험을 나누어 설명했습니다.

## 3. Enemy 기본 프리셋

N=Normal, S=Straight, T=Tanker, Sn=Sniper, Th=Thrower. 구성과 총수는 기획안 기준입니다.

난이도는 동일한 장비와 유사한 지형을 가정한 구성별 상대 평가 초안입니다. 쉬움·보통·어려움·매우 어려움으로 구분하며, 플레이 검증 전입니다.

| 난이도 | 청크 수 | 청크당 Enemy 최대 수 |
|---|---:|---:|
| 쉬움 | 10 | 5 |
| 보통 | 9 | 6 |
| 어려움 | 7 | 7 |
| 매우 어려움 | 4 | 8 |
| 합계 | 30 | |

모든 Chunk는 최소 3마리로 구성합니다.

정렬 기준: 난이도 → Enemy 종류 수 → 총 마리 수 → 타입 순서(N, S, T, Sn, Th). 같은 조건에서는 기존 ID 순서를 유지합니다.

| 청크 ID | 청크 명 | 구성 | 총수 | 난이도 | 제공하는 전투 경험 |
|---|---|---|---|---|---|
| C01 | 기본 무리 | N x 3 | 3 | 쉬움 | 근접 추적과 가속에 대응하며 거리 유지와 무리 처리 경험 |
| C02 | 돌진 무리 | S x 3 | 3 | 쉬움 | 여러 돌진의 예고와 경로를 확인하고 회피 후 반격 |
| C03 | 근접 무리 | N x 4 | 4 | 쉬움 | 근접 Enemy를 모으고 이동 방향을 선택하며 처리 |
| C04 | 소규모 무리 | N x 5 | 5 | 쉬움 | 여러 근접 Enemy를 모으고 공격 방향과 이동 공간 선택 |
| C05 | 기본 돌진 | S x 2 + N x 1 | 3 | 쉬움 | 두 돌진을 피하면서 근접 추적 Enemy의 위치도 함께 확인 |
| C06 | 돌진 정찰 | N x 2 + S x 1 | 3 | 쉬움 | 근접 추적 두 개체ㅈㅈㅈㅈ와 단일 돌진에 함께 대응 |
| C07 | 소규모 저격 지원 | N x 2 + Sn x 1 | 3 | 쉬움 | 작은 근접 무리를 처리하며 저격 사선 확인 |
| C08 | 소규모 폭격 지원 | N x 2 + Th x 1 | 3 | 쉬움 | 두 근접 Enemy의 추적 속에서 폭탄 경고를 피해 접근 |
| C09 | 근접 정찰 | N x 3 + S x 1 | 4 | 쉬움 | 근접 무리의 추적을 피하면서 한 돌진에 대응 |
| C10 | 돌진 지원 | N x 1 + S x 3 | 4 | 쉬움 | 세 돌진의 방향을 확인하며 근접 추적 Enemy도 함께 처리 |
| C11 | 연쇄 돌진 | S x 4 | 4 | 보통 | 여러 돌진 예고와 경로를 읽고 연속 회피 및 반격 |
| C12 | 군집 무리 | N x 6 | 6 | 보통 | 늘어난 근접 압박 속에서 포위를 피하고 퇴로와 공격 기회 확보 |
| C13 | 기본 폭격 | N x 3 + Th x 1 | 4 | 보통 | 근접 무리를 상대하면서 폭탄 경고 지역에서 이탈 |
| C14 | 근접 돌진 무리 | N x 3 + S x 2 | 5 | 보통 | 근접 무리 처리와 두 돌진 회피를 연결 |
| C15 | 중장갑 무리 | T x 1 + N x 5 | 6 | 보통 | Tanker의 방어·돌진과 Normal의 추적 사이에서 공격 대상 선택 |
| C16 | 저격 지원 무리 | N x 5 + Sn x 1 | 6 | 보통 | 근접 무리를 처리하는 동안 저격 사선을 확인하고 접근 여부 판단 |
| C17 | 돌진 폭격 지원 | N x 2 + S x 2 + Th x 1 | 5 | 보통 | 소규모 근접 압박 속에서 돌진과 폭탄 경고를 함께 확인 |
| C18 | 저격 보호 | N x 3 + T x 1 + Sn x 1 | 5 | 보통 | 근접 추적과 Tanker의 방어·돌진에 대응하면서 저격 사선을 확인하고 공격 대상 선택 |
| C19 | 폭격 보호 | N x 3 + T x 1 + Th x 1 | 5 | 보통 | 근접 추적과 Tanker의 압박 속에서 폭탄 범위를 벗어나며 공격 기회 확보 |
| C20 | 집중 폭격 | Th x 5 | 5 | 어려움 | 집중 폭격 속에서 안전한 이동 경로를 찾고 거리를 좁혀 공격 |
| C21 | 이중 중장갑 무리 | T x 2 + N x 3 | 5 | 어려움 | 두 Tanker의 방어·돌진을 확인하며 이동 공간과 공격 기회 확보 |
| C22 | 저격 교차 | N x 3 + Sn x 2 | 5 | 어려움 | 두 저격 사선과 근접 추적을 함께 고려하여 이동 방향 선택 |
| C23 | 돌진과 저격 | S x 4 + Sn x 1 | 5 | 어려움 | 저격 사선과 돌진 경로를 동시에 확인하며 회피 |
| C24 | 돌진과 폭격 | S x 4 + Th x 1 | 5 | 어려움 | 폭탄 범위 밖으로 이동할 때 돌진 경로까지 고려 |
| C25 | 폭격 무리 | N x 3 + Th x 3 | 6 | 어려움 | 여러 폭탄 경고를 피해 이동하며 근접 Enemy 처리 |
| C26 | 근접 압박 1 | N x 3 + S x 4 | 7 | 어려움 | 근접 무리를 상대하면서 돌진 경로를 피해 이동 |
| C27 | 대규모 돌진 | T x 2 + S x 4 | 6 | 매우 어려움 | Tanker의 방어와 두 타입의 돌진에 대응하며 반격 시점 선택 |
| C28 | 원거리 포위 | Sn x 2 + Th x 4 | 6 | 매우 어려움 | 두 저격 사선과 다수의 폭탄 범위를 함께 확인하며 안전한 이동 경로와 접근 기회 선택 |
| C29 | 중장갑 원거리 분대 | N x 2 + T x 2 + Sn x 1 + Th x 2 | 7 | 매우 어려움 | 두 Tanker의 방어와 돌진에 대응하며 저격·폭탄 속 공격 우선순위 선택 |
| C30 | 종합 전투 | N x 3 + S x 2 + T x 1 + Sn x 1 + Th x 1 | 8 | 매우 어려움 | 일반 5종의 공격·이동·스킬을 함께 판단하고 상황별 대응 방법 선택 |

C01~C30의 타입·개수·난이도를 EnemyChunkPreset SO 에셋에 반영했습니다. SO 에셋 이름은 영어로 관리합니다. 에셋 위치: `Assets/07.Datas/Enemy/ChunkPresets`.
