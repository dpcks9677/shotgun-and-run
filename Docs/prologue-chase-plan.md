## 1. 목표

- 지금의 "뒷걸음질 + 일정한 간격 + 일정한 박자" 추격을 **빠르고 위협이 점점 다가오는 질주 장면**으로 바꾼다.
- 실제 이동 속도를 올리고, 거리가 줄어드는 만큼 시작 위치를 왼쪽으로 옮겨 **추격 길이를 5~6초**로 유지한다 (A안).
- 샷건 연사 간격 **0.8초 규칙**을 컷씬 전체에서 지킨다.
- 음악(75 BPM, 한 박 = 0.8초)과 사격 · 킬 타이밍을 맞춘다.

**제외:** 복도 타일맵 확장(B안), 발밑 먼지 · 스피드 라인 이펙트(이후 별도), 고블린 수 변경.

## 3. 타임라인 (추격 시작 = 0초, 한 박 = 0.8초)

플레이어 이동은 구간별 속도로 나눈다. 총 50.5u, 약 5.9초.

| 구간 | 거리 | 속도 | 시간 |
|---|---|---|---|
| 1. 출발 | 8u | 7 | 1.14초 |
| 2. 가속 | 22u | 9 | 2.44초 |
| 3. 전속 | 16.5u | 10 | 1.65초 |
| 4. 감속(게이트 앞) | 4u | 6 | 0.67초 |

사격은 6발, 박에 맞춘다. 3발 뒤 한 박을 쉬어 박자를 흔든다.

| 발 | 시각 | 고블린 간격(앞 개체) | 비고 |
|---|---|---|---|
| 1 | 0.8초 | 2.6 | 첫 킬. 추격이 시작된 걸 알린다 |
| 2 | 1.6초 | 2.2 | |
| 3 | 2.4초 | 1.8 | |
| (쉼) | - | **0.6** | 한 박 동안 바짝 붙는 아슬아슬한 순간 |
| 4 | 4.0초 | 1.5 | 쉼 뒤 터지는 킬 |
| 5 | 4.8초 | 1.3 | |
| 6 | 5.6초 | 1.2 | 마지막 고블린. 줌 최대 · 흔들림 최대 |
| 도착 | 약 5.9초 | - | 감속 구간에서 도착 |

킬 간격이 항상 **0.8초 이상**이라 연사 규칙을 지키고, "총알 없이 쓰러짐"도 생기지 않는다. 쏜 뒤 간격을 다음 값으로 바꿔 `CrowdFollow`를 다시 호출한다(이전 명령은 자동 취소). 따라가기 속도는 그 구간의 플레이어 속도에 맞춘다(작으면 간격이 벌어진다).

## 4. 코드 변경 (`PrologueShelterCutscene` 3비트)

1. **이동**: `MoveBackward` 대신 `MoveTo` 구간 연쇄. `MoveRoutine`은 구간 시작에만 이동 방향을 바라보게 하므로, 쏘는 순간 `Face(left)`를 호출하면 방향이 유지되고 쏜 뒤 `Face(right)`로 되돌린다.
2. **사격 루프**: 킬 시각 배열(박 번호)과 간격 배열로 둔다. 마지막 총성 이후 연사 간격을 지키는 기존 대기(`_nextShotAt`)는 그대로 쓴다.
3. **박 정렬**: 추격 시작 직전에 긴장 곡의 재생 위치를 읽어 다음 박 경계까지 기다린 뒤 시작한다(`AudioManager`에 재생 위치 프로퍼티 1개 추가, 최대 0.8초 대기). 이후 사격은 시작 시각에 0.8초 배수를 더한 시각에 쏜다.
4. **카메라**: 시작에 `CameraToPlayer(블렌드 짧게)`, 사격마다 `CameraShake(0.06, 0.15)`, 추격 내내 `CameraZoomScale(0.92, 약 5초)`, 마지막 킬에서 `CameraShake(0.12, 0.3)`, 도착에서 `CameraZoomReset`.
5. **도착(7번)**: 감속 구간(속도 6) 뒤 `CameraTo(MeetCamera, 짧게)`로 스냅한다. 긴장 곡은 도착 시 0.15초로 빠르게 끊고, 경계 곡은 **경비병 대사(`_guardSpotted`) 첫 줄**에서 시작한다. 그 사이 약 1초의 무음이 "안도"를 만든다.
6. **수치는 SerializeField**로 두고 기존 `_playerWalkSpeed` · `_goblinCatchUpSpeed` · `_retreatFireInterval`은 구간 속도 · 간격 배열로 대체한다. 불필요해진 필드는 정리한다.

## 6. 확인 항목 (구현 전 · 후)

구현 전:
- 서쪽 복도 바닥이 실제로 x -66까지인지(타일맵 끝), 카메라가 그 너머 빈 곳을 비추지 않는지(카메라 제한 영역 유무). 비추면 시작 화면 왼쪽이 허공이므로 카메라를 고정하거나 시작을 오른쪽으로 당긴다.
- 샷건 연사 간격이 정확히 0.8초인지. 박 간격과 같아 프레임 오차로 "총알 없이" 판정될 수 있으면 사격을 박 시각 + 0.02초로 둔다.

구현 후 플레이 확인:
- 총성이 어떤 구간에서도 0.8초 이내로 겹치지 않는다(앞 장면의 총성 묶음과 추격 첫 발 포함).
- 킬 6발이 모두 총알과 함께 쓰러지고, 마지막 킬이 도착 직전에 일어난다.
- 고블린이 화면 왼쪽 밖에서 달려 들어오고, 한 박 쉬는 구간에 바짝 붙는다.
- 추격 중 플레이어가 화면 밖으로 밀리지 않는다.
- 도착 후 약 1초 무음, 경비병 대사에서 경계 곡이 시작한다.

| 복도 시작이 허공으로 보임 | 6장 확인 항목 참조. 시작 위치 되돌리기 또는 타일맵 확장(B안) |
| 박 정렬이 어긋나 음악과 샷이 따로 놈 | 곡 재생 위치 읽기가 실패하면 박 정렬을 건너뛰고 일정 간격으로 쏜다 |

## 8. 이번에 반영한 것 (총격음 간격 규칙)

- 인트로 총성 묶음 3개의 간격이 규칙(0.8초)보다 짧거나(마지막 묶음 0.5초), 대사를 빨리 넘기면 서로 겹쳐 간격이 무너졌다.
- 총성 재생을 컷씬 단위의 단일 일정(`_nextShotAt`)으로 모아, 어떤 묶음이든 **앞 총성 뒤 0.8초 이상**이 되도록 뒤로 미룬다.
- 추격의 첫 사격도 같은 규칙으로 앞 장면 총성 뒤에 서도록 대기한다.
- 파일: `PrologueShelterCutscene.cs`, `CutsceneContext.Audio.cs`(`PlaySfxBurst`에 `startDelay` 인자 추가).

## 9. 어둠 속에서 나오는 연출 (구현됨)

서쪽 복도의 서쪽 끝은 어둡고 게이트 쪽으로 갈수록 서서히 밝아지게 했다. 추격이 "어둠 속에서 뛰쳐나와 쉘터의 빛으로 들어가는" 흐름이 된다.

| 항목 | 값 |
|---|---|
| 오브젝트 | `ShelterScene` 루트 `PrologueCorridorDarkness` (SpriteRenderer 1개, 씬에만 존재) |
| 스프라이트 | `Assets/04.Sprites/Light/CorridorDarkness.png` (256×64, 청흑색, 가로 알파 그라데이션) |
| 위치 · 크기 | 중심 x = -50, 가로 60u(x -80 ~ -20) × 세로 24u. 서쪽 20%는 알파 0.8로 고정, 이후 smoothstep으로 x -20에서 0 |
| 정렬 | Foreground / -100: 캐릭터 · 무기 · 총알 위, 월드 텍스트(Foreground / 10) 아래 |
| 밝기 | x -64 약 0.8(고블린 윤곽만 보임), x -50 약 0.55, x -36 약 0.2, x -20 이후 원래 밝기 |

- 전역 빛(Global Light 2D)을 쓰지 않아 쉘터 홀 · 다른 구역의 조명에 영향이 없다. 바꾸기 쉬운 단일 스프라이트다.
- 게이트(x -13.5)는 그라데이션이 끝난 지점 뒤라 원래 밝기 그대로라서, 도착하는 순간 "빛 안으로 들어왔다"는 대비가 생긴다.
- 확인한 렌더: x = -64 / -50 / -36 / -22 지점에서 카메라 시점 렌더(고블린 6마리 윤곽 식별 가능).
- 조정: 어둠 정도는 스프라이트 알파(0.8)나 오브젝트 색으로, 범위는 오브젝트 위치 · 스케일로 바꾼다.

## 10. 구현 결과와 플레이 검증 (2026-10-14)

구현: `PrologueShelterCutscene` 3비트를 박(0.8초) 단위 루프로 교체했다. 박마다 `MoveTo` 속도(`_runSpeeds`)와 `CrowdFollow` 간격(`_goblinGaps`)을 다시 지정하고, `_shotBeats`의 박에서만 돌아서 쏜다. 씬은 `PlayerStart` x -64, `CS_PROLOGUE_SHELTER_Goblins` 부모 x -8.5(자식 6마리). 컷씬 에셋의 수치도 함께 바꿨다(코드 기본값만 바꾸면 에셋의 옛 값이 남는다).

에디터 플레이(`CutsceneDirector.PlayDebug`)에서 프레임마다 기록한 값:
- 추격 시간: x -64 → -13.5, 약 **6.0초** (현재 9초). 첫 이동 속도 6.5 → 최대 9.5 → 게이트 앞 감속.
- 시작 박 정렬: 추격 시작이 긴장 곡 재생 위치의 박 경계(11.2초 = 14박)에 맞고, 총성은 이후 0.8초 간격으로 박에 떨어진다.
- 카메라: 시작 0.3초 블렌드, 추격 중 크기 8.44 → 7.78, 도착에서 대면 구도로 스냅.
- 음악: 긴장 곡이 게이트 도착에서 끊기고, 약 1.5초 무음 뒤 경비병 첫 대사에서 경계 곡, "돌파구" 줄에서 희망 곡 시작.
- 화면: 어둠 그라데이션 속에서 고블린 6마리와 쓰러진 개체가 식별된다.

## 11. 보완 (2026-10-14, 플레이 피드백 반영)

| 피드백 | 조치 |
|---|---|
| NPC 장면 대기가 김 | 대형 이동(경비병 · 로나) 완료를 기다리지 않고 바로 추격으로 이어 간다. 이동 속도를 올리고(로나 2.3 → 3.2, 경비병 대형 3 → 4, 경비병 1 걸음 1.4 → 2), 경비병 경계 말풍선을 1.2 → 0.8초로 줄였다. 인트로 총성 묶음을 3 · 3 · 6발에서 2 · 2 · 3발로 줄이고, 추격 시작은 첫 사격만 앞 총성 뒤 0.8초를 지키면 되게 완화했다 |
| 로나가 이동할 때 카메라가 따라붙어야 함 | 시작 때 로나를 따라가고, 로나가 바리케이트로 이동하는 동안 · 대면 구도로 걸어 나올 때 로나를 따라간 뒤 `MeetCamera`로 돌아온다 (`_lonaCameraBlend`) |

| 너무 바짝 붙어서 추격이 끝남 | 쉬는 박을 없애고 킬을 박 1~6에 몰아 마지막 킬이 게이트 약 9.4u 앞(약 1.4초 전)에서 끝나게 했다. 속도를 6.5 → 9 → 7로 약간 낮추고, 마지막 킬의 고블린 간격은 2.4(최소 1.4는 4번째 킬) |
| 뒤를 보며 계속 쏘는 게 나음 | 방향 전환을 없앴다. 추격 내내 뒤를 겨눈 채 뒷걸음질로 달리며 박마다 쏘고(조준만 바뀜), 마지막 킬 뒤에만 앞으로 돌아 남은 복도를 달린다 |

플레이 검증(에디터): 사격 6회 모두 실제 발사(탄 감소 6회, 간격 0.80~0.82초), 박 경계 +0.03~0.06초에 정렬, 추격 6.2초, 마지막 킬 x -22.9(게이트 -13.5 앞), 대사 종료 → 추격 시작 약 1.0초.
