# [QA] Shotgun and Run 진행 사항 평가표

> **기준 문서:** [Game_QA_Feedback_Integrated.md](./Game_QA_Feedback_Integrated.md)  
> **작성일:** 2026-10-14  
> **목적:** 지인 QA에서 도출된 개선 항목과 버그의 진행 여부, 수정 여부, QA 재테스트 결과를 기록한다.

## 1. 평가표 사용 방법

1. `진행 상태`를 `미착수 → 기획 중 → 개발 중 → 부분 완료 → 완료` 순서로 갱신한다.
2. 실제 수정이 코드나 콘텐츠에 반영되면 `수정 완료`에 체크한다.
3. 수정된 빌드에서 재현 여부를 확인한 뒤 `QA 재테스트`에 체크하고 결과를 비고에 기록한다.
4. 버그는 재현되지 않는 것만으로 끝내지 말고, 기존 재현 조건과 주변 케이스까지 함께 확인한다.
5. 우선순위는 관리용 초안이므로 개발 일정에 따라 변경할 수 있다.

### 상태 정의

| 상태 | 의미 |
|---|---|
| 미착수 | 검토나 작업을 시작하지 않음 |
| 부분 완료 | 일부 조치 완료, 추가 작업 필요 |
| 완료 | 구현 또는 수정 완료, QA 재테스트 대기 |
| 검증 완료 | 수정 후 QA에서 정상 동작 확인 |
| 보류 | 우선순위 또는 방향성 결정 전까지 보류 |

### 체크 기준

- [ ] 수정/반영 완료
- [ ] QA 재테스트 완료
- 재테스트 결과: `미실시 / Pass / Fail`

## 2. 전체 진행 현황 요약

| 구분 | 개수 | 기록 |
|---|---:|---|
| 전체 평가 항목 | 79 | 기존 항목 보강 및 추가 QA 7건 포함 |
| P0 긴급 | 2 | 예찬-B의 조준각 역전, 컷씬 스킵 |
| 현재 부분 완료 | 2 | 던전 기본 조도 하향, 대시 무적 시간 상향 |
| 검증 완료 | 0 | 재테스트 후 갱신 |
| 보류 | 1 | 민석-E의 전체 맵 규모 축소 검토 |

> 위 개수와 상태는 작업 진행에 따라 갱신한다. `현재 부분 완료`는 기존 QA 문서에 기록된 조치 사항만 반영했다.

## 5. 릴리스 전 최종 확인

- [ ] P0 버그가 모두 수정되고 재현되지 않음
- [ ] 진행을 막는 레벨 콜리전 문제가 없음
- [ ] 튜토리얼에서 핵심 입력과 진행 목적을 알 수 있음
- [ ] 퀘스트 목록·목표·퀘스트 아이템을 확인할 수 있음
- [ ] ESC로 옵션·메뉴에 접근하고 게임을 일시정지할 수 있음
- [ ] 무기 획득 시 과도한 섬광 없이 설명 또는 강조 효과가 표시됨
- [ ] 총을 들었을 때 조준점으로 발사 방향을 쉽게 예측할 수 있음
- [ ] 로비의 상호작용 대상에 대화·열기 등 안내가 표시됨
- [ ] 로비 NPC 이름과 캐릭터 상하 방향 스프라이트가 표시됨
- [ ] 자동 저장 상태를 문구로 확인할 수 있음
- [ ] 남은 적 수 표시가 중앙 시야를 방해하지 않음
- [ ] 맵과 탈출 포탈의 위치·상태를 파악할 수 있음
- [ ] 전투 존 이탈, 낙석, 오브젝트 대시 등 주요 콜리전과 전투 경계가 의도대로 작동함
- [ ] 대시·탄창·체력·퀵 슬롯 HUD를 전투 중 인지할 수 있음
- [ ] 탄약 소진 시 장전과 장전 타이밍 입력이 의도한 규칙으로 작동함
- [ ] 초반 몬스터와 습격 난이도가 의도한 수준임
- [ ] 주요 해상도에서 UI가 잘리지 않음
- [ ] 수정 사항이 기존 코어 게임플레이 재미를 훼손하지 않음
